## 豆包链路请求ext参数

在豆包链路中ext map中添加以下参数

key和value均为字符串类型

<table><tbody>
<tr>
<td>

key

</td>
<td>

value

</td>
</tr>
<tr>
<td>

`vehicle\_biz\_params`

</td>
<td>

```JSON
{
    "vehicle_id": "123456",
    "vehicle_type": "SAI_OS",
    "channel": "seres",
    "channel_app_id": "99210",
    "coordination_info": {
        "client_version": "x.x.x-xxxxx"
        "request_id": "2f426d00-461d-40b1-8931-a582f5b3bd88", // 请求ID，使用于端云结果仲裁
        "round_id": 1, // 轮次信息
        "sound_zone": "副驾", // 音区
        "tts_emotion": "用夹子音跟我说", // TTS 合成时使用的情感
        "force_sami_tts": false, // 强制使用Sami TTS（若会TTSEmotion为空，则强制把TTSEmotion置为用户query, 会让所有文本都走Sami TTS合成）
        "direct_agent": ""// 强制指定直接执行某个Agent
    }
}
```

    1. 如果是trace链路，直接点击对应case，查看【edge2edge\-time\-cost】span即可
