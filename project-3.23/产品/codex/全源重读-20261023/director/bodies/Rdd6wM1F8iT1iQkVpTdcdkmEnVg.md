## 五、车机交互与 UI 规范

### 1\. 生命周期状态

1. **生成中**

    - 动效加载

    - 话术：豆包下发到客户端

2. **生成成功**

    - 图片（1\~10 张）

    - 点击放大、支持翻页

3. **生成失败**

    - 统一失败占位图

### 2\. 交互指令

- 打开图片 / 放大第 X 张

- 重新生成 / 再生成 X 张

- 修改第X张

## 六、异常与稳定性设计

1. **超时机制**

    - 生图超时时间：X秒

2. **失败策略**

    - 部分失败：展示成功图 \+ 失败占位

    - 全部失败：统一失败 UI

3. **并发冲突**

    - 同一用户只允许 1 个生图任务

    - 新请求进入：提示“正在生成中”

4. **网络弱网/断网 **

    - 明确提示网络异常

---



## 七、安全与合规

- 图片内容审核：模型侧自带过滤

- 车机不缓存敏感/违规内容

- 水印防泄露
