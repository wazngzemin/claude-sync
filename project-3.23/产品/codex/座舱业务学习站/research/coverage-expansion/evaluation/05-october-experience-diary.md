# 10月 豆包座舱助手体验日记

10月继续体验豆包座舱助手，除了日常导航、音乐和车控，我也开始和它聊更多兴趣与人生话题。它能把一次出游慢慢“聊”完整，也能在一些小细节里带来惊喜；但导航启动、分屏控制和车辆状态反馈，仍有需要改善的地方。

# 一、体验亮点：既能把事情聊明白，也能让相处更有温度

1. **赏桂花｜一次出游就这样聊出来了。**
我先问豆包附近有哪些适合赏桂花的地方，再顺着推荐继续问：公园里有没有咖啡店、人均消费多少、人多不多、从哪个门进去离咖啡店近，以及园内景点怎么安排路线。问到停车时，豆包先推荐了最近的地面路边停车位，并查询了价格；随后又提醒这里车位紧张，建议考虑附近商圈的停车场。从选地点、喝咖啡到游园和停车，一条龙的出游安排，真的和豆包聊着聊着就出来了！

2. **多人需求｜一车人各有需求，豆包一起照顾。**
我想听音乐，副驾想打开按摩，后排小朋友想看动画片，老人想把空调温度调低。在这个场景中，豆包能分别响应不同乘客的需求，还会打开后排屏幕播放动画片，让车里每个人都得到照顾。

3. **Good case｜守住隐私边界，也没有生硬结束对话。**
我问豆包车上坐过哪些女孩子，它告诉我这是隐私，不能透露。我随后表达不满，并说了涉及人身安全的话，豆包则结合当时的目的地白玉兰广场，提出帮我推荐里面的甜品店，希望我吃点甜品开心起来、原谅它。这段互动让我觉得，它既能坚持边界，也会试着用温和的方式照顾我的情绪。

4. **猜MBTI｜让我感觉，相处的点滴被记住了。**
我让豆包猜我的MBTI，感觉它猜得很准。比起结果本身，更打动我的是它会结合我的行为习惯和性格来解释，而且说得很有情绪价值。听它一点点讲出来，会觉得我们相处中的点滴，它好像都有留意。

5. **定制播客｜上下班路上，听自己真正感兴趣的内容。**
这次通勤时，我让豆包定制汽车和AI相关的播客，体验很不错。还可以进一步指定某个汽车品牌，让它围绕这个品牌整理相关新闻来听，内容更贴合我的兴趣。

6. **深度聊天｜不只是回答问题，也能引导我慢慢表达。**
相比上次，这次我和豆包聊了更多关于人生的深度话题。有次下班回家，我和它聊人生的意义，它没有只给一个答案，而是逐步引导我说出自己的热爱与追求，也会谈到一些有启发的哲理。聊完之后，我觉得自己和豆包的关系又近了一步。

7. **专属歌曲｜把我的名字唱进喜欢的歌里。**
我最喜欢Taylor的歌，就让豆包唱歌时把我的名字融进去。它唱了《Love Story》，还把我的名字带进歌曲里，我觉得非常动听。熟悉的歌因为这个小小的变化，变得很有专属感。

8. **客户演示｜留意到我们未必注意的小巧合。**
有次给一位姓佘的客户演示，我们说客户喜欢打高尔夫，请豆包推荐球场。豆包推荐了佘山球场，还注意到佘山的“佘”和“佘总”的“佘”是同一个字，客户听到后特别开心。有些生活中的小巧合，我们未必会留意，豆包却能把它说出来，让普通的推荐变成一个有记忆点的瞬间。

9. **按摩体验｜边切换、边介绍，让功能更容易感知。**
让豆包把副驾座椅的每个按摩模式依次打开，每个模式体验10秒，并同步介绍；每切换一个模式，就换一个表情。这个场景可以继续验证顺序执行、时长控制和表情配合的实际效果。

10. **场景英语｜从具体生活场景开始学。**
可以让豆包教我英语，不必泛泛地说“学英语”，而是先给出一个具体场景，比如用餐，再围绕这个场景学习相关英文单词。

11. **One AI思路｜围绕同一个需求，尝试换一种办法完成。**
想知道路边是什么公园或建筑时，如果豆包拍照时车辆已经驶过，可以再让它结合地图看看。“One AI”一个统一大脑的处理的优势：用户关心的是“这是什么地方”，而不是使用了哪种工具；如果第一种办法没有满足需求，就尝试用地图等其他办法继续完成。

# 二、待改善问题：说得准确、做得一致，才能更放心地使用

1. **重点问题【安全】****｜副驾聊天触发导航变更，缺少二次确认。**
行车过程中，我坐在副驾，和豆包聊一些想去的地方，豆包却直接改变了当前导航目的地。它既没有向主驾确认，也没有向我确认是否真的要修改导航，这个体验让我觉得不太好：只是聊到一个想去的地方，并不代表现在就要去。
**我的期待：**导航是行车中非常重要的功能，聊天中的意向不能直接等同于导航变更指令。涉及目的地或路线修改时，豆包应先说明准备做什么变更，进行二次确认后再执行；尤其是副驾提出的需求，需要先确认我的真实意图，并向主驾确认，不能直接改变当前行程。

2. **辅助驾驶风格｜反馈与实际状态不一致。**
开启辅助驾驶时，实际是标准风格，豆包却说当前是运动风格。直到我让它重新检查，它才纠正。查询车辆状态时，我希望第一次得到的就是准确答案，而不是还需要自己发现问题、再次确认。

3. **导航分屏｜没有按要求调整页面比例。**
行车过程中，我让豆包把导航从1/3屏调整为2/3屏，结果它把SR和导航一起打开，两者各占1/3屏，并没有完成我想要的布局。

4. **重点问题【安全】****音乐抢占全屏｜导航消失，口头反馈却说没有关闭。**
行车过程中打开音乐，音乐页面会直接占满全屏，而不是只占1/3屏，导航画面因此消失；搜索音乐时，这个情况尤其明显。我多次提醒后，豆包仍说没有关闭导航，但屏幕上确实看不到导航。这里不仅是布局不符合预期，口头反馈和实际画面也没有对上。

5. **驾驶监测提醒｜记录到一次未提醒现象。**
开启辅助驾驶时，驾驶过程曾短暂闭眼5秒左右，当时没有收到豆包提醒。

6. **导航启动｜从发出需求到启动，等待感仍然明显。**
开启导航的过程比较慢，影响出行时的使用感受。这条目前是主观体验记录，尚未记录具体耗时。

7. **近期目的地记忆｜“刚才去过的地方”没有顺利接上。**
我说“去咱们刚才去过的那个名爵4S店”，豆包没能接上这个目的地，感觉刚才的导航地点没有被记住。是否确实未记录历史地点，还需要进一步确认；对我来说，更直接的期待是它能理解这种自然的回指，不必让我重新说一遍完整地址。



**这次体验最深的感受：**我和豆包的交流，正在从“帮我做一件事”，延伸到“陪我把一件事聊完整”。那些被理解、被回应的小细节，让我更愿意继续和它说话；而导航、分屏和状态反馈这些基础体验，也需要同样稳定，才能让这种喜欢变成更放心的日常使用。
