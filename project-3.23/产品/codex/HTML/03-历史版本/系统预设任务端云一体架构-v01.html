EDGE · CONFIRM_LOCAL

天气/路况保护

  • 雨/湿滑 → 湿滑模式
  • 雪/覆冰 → 雪地模式
  • 浓雾 → 后雾灯

EDGE · SILENT

儿童/宠物儿童锁

规则P0待收口
  • 不出卡、不播TTS
  • 非P持续还是切D事件待定
  • 儿童端状态优先；宠物VLM
  • 左右门/车门安全门禁待定
  • 静默车控+真实状态回读
PLACEMENT TBD · SILENT

后视镜自动加热

部署待确认
  • 雨天+<70km/h+非P
  • 洗车退出→端侧15分钟
  • 湿度>60%+温差>5℃
  • 不出卡、不播TTS
  • 温差窗口/退出策略待定
HYBRID · CONFIRM TBD

  • FOUND+用户授权才可继续
