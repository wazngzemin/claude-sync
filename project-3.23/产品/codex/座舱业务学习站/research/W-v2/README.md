## W 最难讲清的 5 个点

1. **看到按钮与可用对象之间有两次交接。** ASR把字写对，不能代替页面业务注册“词—目标”；主动注册、框架自动扫描和奇瑞拟议SDK必须按车型与阶段分开。最直接的失败例子是“暂停视频”已经听对却未命中。
2. **“第二个/就这个”不能一律解释成模拟点击。** 普通Planner候选列表、本地注册词和系统通知卡动态工具有三条不同路径；动态工具只给出了卡片上下文、select_button和下发协议，没有完整的序号、指代、多屏或过期卡片算法，后续写作必须守住这个证据边界。
3. **模型选中不等于客户端做成。** matchVC、INTERCEPTED、select_button、SDK返回、真实页面变化和业务目标完成是不同节点；控件走车企执行，抖音可直调SDK，不能都写成同一种点击；动态工具的真实执行回执契约仍不完整。
4. **四类卡片的手点与语音不天然同路。** Planner卡不注册词、Advisor手点可模拟Query、系统通知用临时选择工具、端侧通知走本地词表；卡片退出、撤词/卸载、页面切换及多屏保持还可能改变可选对象，不能只画一条“所有按钮都上云”链。
5. **结果回写要解释“云端下一轮真的知道了什么”。** 本地被截获请求仍需上报，来源标记和车型类型不同，8/31上报能力与9/15历史格式改造也不同；“退出导航→确认”事故说明服务端上线、车端升级、历史构造和下一轮使用是不同验收点，通用记账机制只回指R/I。
