# Codex 工作规则

## 浏览器收尾

- 仅在完成任务确有需要时打开浏览器。
- 任务完成且已完成验证后，关闭本任务新建的浏览器标签页或窗口。
- 不要关闭用户在任务开始前已打开的标签页、窗口或整个浏览器；无法可靠区分时，先向用户说明，不要擅自退出浏览器。

## HTML 产出与版本管理

- 所有新生成的 HTML 必须保存到本目录下的 `HTML/`；不得散落在项目根目录、桌面、下载目录或其他临时位置。
- 根据状态保存：制作中的文件放 `HTML/01-进行中/`；确认可交付的文件放 `HTML/02-已交付/`；被后续版本替代的文件放 `HTML/03-历史版本/`。
- 每一个 HTML 文件名都必须包含版本号，格式为：`<主题>-vNN.html`，例如 `端侧触发器评审稿-v01.html`。
- 每次修改 HTML 必须创建递增版本（`v01`、`v02`、`v03`……），不得覆盖或删除已有版本。需要归档时，将旧版本移至 `HTML/03-历史版本/`，文件名保持不变。
- 需要复用的模板、命名说明或发布说明保存到 `HTML/00-规范与模板/`。
