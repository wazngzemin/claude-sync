另一台 Mac：Claude Code + 3.23 同步

优先使用提供的「Claude同步安装器.app」：
1. 将整个 ZIP 传到另一台 Mac，解压后打开安装器。
2. 安装器检查 Git/Python 3 等依赖，使用这台电脑已有的 GitHub 登录下载或更新 claude-sync。
3. 桌面出现「Claude同步管理.app」后，点击“拉取全部（Claude + 3.23）”。
4. 查看常驻结果区，云端及各项均成功才算完成。本机缺失来源会明确列为跳过。

同步范围：Claude 配置、技能、插件、项目记忆，以及 ~/Desktop/3.23 工作文件。
3.23 中包括由 Codex 生成的工作文档，但不读取或恢复独立 ~/.codex 配置、聊天数据库。
文档、图片、音视频、压缩包都包含；Git内部目录、依赖/临时缓存和密钥文件排除。
大文件自动分块并校验还原。拉取覆盖前备份，不删除本机独有文件。

安装器不携带账号或密钥。另一台 Mac 需要对 wazngzemin/claude-sync 有访问权限。
已有 GitHub CLI 时，可在终端运行 gh auth login，选择 GitHub.com、HTTPS 和浏览器登录。
没有 GitHub CLI 时，使用已配置的 Git HTTPS 凭证；安装器不会假装已经登录。
Permission denied / Authentication failed 表示凭证或访问权问题。
网络失败、目录不是仓库、本地存在未提交修改或分支冲突时会停止并保留数据，不要强制重置。

修复前程序与旧 App 备份在 ~/.claude-sync-state/portable-backup-*。
面板拉取前的数据备份在 ~/.claude-sync-state/pull-backups/。
命令行拉取备份在 ~/.claude-sync-state/pull-backup.*。
安装日志在 ~/.claude-sync-state/portable-install-*.log。

两台都使用相同 App；一台推送成功后，另一台再拉取，避免同时修改同一文件。
