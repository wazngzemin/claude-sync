AI汽车主动推荐技术评审
背景
主动推荐是指由系统根据当下的情况，主动地向用户发起问询或者推荐，同时需要承接后续用户的话语到主链路中。
目标
朝着长期通用的方案去建设流程，但是S0X期望落地的场景有：
车控场景（监测到当前温度较高，播报：“为你打开空调”，同时执行车控）
planner直出问候语（上车时播报，“你好呀小兄弟，晚上要不要一起去吃火锅”）
基于这个目标，我们会梳理出理想链路，部分需求暂时不考虑，比如：
本期只考虑实时执行和下发的情况，延时或者定时的情况暂时不考虑
本期暂时不考虑主动推荐的限流策略
本期不考虑出多个意图的情况，后期依赖planner的规划实现这块

trigger_method // 扩展一个主动推荐的枚举
TriggerMethod_UserInput       TriggerMethod = 1 // 用户输入
TriggerMethod_UserState       TriggerMethod = 2 // 座舱根据用户状态自动触发
TriggerMethod_VehicleState    TriggerMethod = 3 // 座舱根据车辆状态自动触发
TriggerMethod_Environment     TriggerMethod = 4 // 环境触发，如天气、时间等
TriggerMethod_ScheduledTask   TriggerMethod = 5 // 定时任务触发
TriggerMethod_SystemTriggered TriggerMethod = 6 // 系统触发，预留场景
TriggerMethod_Emergency       TriggerMethod = 7 // 紧急情况，如车内有婴儿但锁车无空调等
