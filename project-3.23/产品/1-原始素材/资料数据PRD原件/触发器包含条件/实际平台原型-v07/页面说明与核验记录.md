# 触发器配置平台交互原型 v07

## 本次改动

保留 v06 对齐实际平台的导航和场景表单，补回之前的简单模式与 Workflow 判断图。闪念新增的视觉目标判断、固定正文普通通知，继续放在共用的条件和动作区域，不另做独立后台。

两种模式共用基础信息、发布范围、动作和次数／间隔策略。简单模式用动态与静态条件组；Workflow 用条件节点、模型推理节点及连线表达判断关系。是否选择 Workflow，不等于是否走 DT。

## 怎样演示

1. 打开 v07，顶部“业务示例”可选择儿童／宠物、充电前置、后视镜缺口、闪念或简单车速条件。案例阈值与信号字典仅供评审，不是已确认可发布配置。
2. 在“配置模式”选择简单或 Workflow。切换提示中取消会保留输入；继续切换不会自动转换判断内容，两种判断草稿各自保留。
3. 简单模式可新增条件组并填写条件。闪念简单例可配置视觉判断目标及固定通知正文。
4. Workflow 可增加条件／推理节点，点击节点编辑属性，选择起点与终点连线。多个前驱汇合的 AND／OR，与节点内部条件关系分别配置。
5. 点击“校验判断图”。循环、自连、重复连线、非唯一终点和缺失配置会阻止通过；后视镜缺口例的洗车信号未接入，不能保存为完整可用场景。
6. “保存本地草稿”后刷新可恢复完整定义。“新建场景”保存到本地列表；已有 Workflow 只读，复制才可修改判断定义。
7. “本地试跑”人工指定 PASS／REJECT／UNKNOWN，不调用真实信号、模型或车辆。条件通过、动作接收、卡片展示、车辆结果分别展示。
8. “触发记录”选择赛力斯和虚拟车辆 DEMO-VEHICLE，刷新后可查看本次 Workflow；历史详情使用当次定义快照，不套用当前草稿。
