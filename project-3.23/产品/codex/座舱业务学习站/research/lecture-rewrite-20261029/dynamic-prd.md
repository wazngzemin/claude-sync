# 一期需求

## 背景

### 背景

动态示例是修复 Planner Badcase 的核心手段：一条「用户 Query → 决策分析」的示例对，在推理时按相似度检索、注入到 SP 的 `\{\{scenario\_sample\}\}` 槽位，引导模型对同类 Query 做出正确决策。目前动态示例以 **Excel 手工维护成本高**



### 目标

1. 提供一个 Web 配置后台，CQC 同学可直接完成动态示例的**查找 / 新增 / 修改 / 删除**，替代 Excel。

2. 支持**按环境配置**，先落地 SFT 版本，后续可扩展多环境。

## 功能需求

### 列表与查找 

- 默认以表格展示全部动态示例，列：Query、决策分析（超长截断）、操作人、更新时间。

- 顶部搜索框：按 **Query 关键词**模糊搜索。

- 排序：按更新时间倒序默认；支持点列头排序。

- 分页：每页 20/50/100 可选。



### 新增 

**新增示例**：填写 Query 和决策示例



### 修改

- 列表点「编辑」，可进行编辑。

- 若 Query 发生变化，需重建该条检索索引。



### 删除 

- 列表点「删除」，二次确认弹窗后删除。



### 环境配置 

- 顶部提供**环境切换**，切换后列表/编辑均作用于该环境。

- 每条示例归属一个或多个环境；

- 先落地单一 SFT 环境，V2 再放开多环境。



### 方案

- 目前仅支持sft动态示例



### 操作日志 

记录每次新增/修改/删除的：操作人、时间。

因动态示例直接影响线上 Planner 决策，保留审计可追溯问题来源。

### 2\.1 添加查重拦截

- 单条添加与批量导入，均对新 query 与库内已有 query 做语义级相似匹配。

- 检出相似时展示已有条目（ID / query / 决策分析摘要 / 添加人 / 时间），三选一：**取消添加** / **覆盖更新**/ **仍要新增**。

- 相似多条时全部列出，逐条判断。



### 2\.2 全量批量导出

- 一键导出当前车企/环境的全量示例为 Excel/CSV（可按车企、环境筛选）。

- 导出字段为全字段：ID / 车企 / query / 决策分析 / 其他说明 / 状态 / 环境 / 添加人 / 批次号 / 关联 bug / 自测凭证 / 时间。



### 2\.3 批量导入 （待定）

- 列固定：车企 / ID / query / 决策分析 / 其他说明 / 环境 / 操作类型（新增/更新/删除），不允许合并单元格。

- 新增行 ID 留空；更新/删除行必填 ID，按 ID 匹配；ID 不存在的行报错跳过并列入报告。

- 批量删除二次确认：展示将删除的条数和内容摘要。

- 格式校验（列乱/字段缺失/操作类型非法）不通过则整单报错并指明问题，不静默容错。

- 批量操作生成批次号和操作报告。



### 2\.4 审核上线

- 示例增加状态字段：草稿（不参与线上检索）/ 已上线（参与检索注入 SP）/ 已驳回。

- 审核人可配置（1\-N 人，当前配置为王泽民、赵晓朝）。

- 审核页逐条展示内容，自动附带库内相似条目对照；支持单条通过/驳回、批量通过；驳回必填理由，导入人可见、可改后重新提交。

#### 2\.5\.2 平台侧

1. 列表页增加车企/渠道、场景域筛选和展示列；环境继续沿用现有筛选。

2. 新增/编辑页增加：

    - 车企/渠道：多选；

    - 场景域：单选舱内/舱外；

    - 环境：单选。

    - 车型：**EREV 220KM 磷铁   STDEREV 220KM 磷铁   COMEREV 300KM 磷铁   COMEREV 300KM  磷铁 LUX**[【知识库7】IS4PR配置表\_20260814](https://bytedance.larkoffice.com/sheets/R1jxsFYkGhH50etAJcEcFqtznRC)

3. 通用示例可同时勾选多个车企标签，修改一次对所有已选车企生效。

4. 如果同一 Query 在不同车企或场景域下需要不同决策，应建立生效范围不重叠的独立条目。

5. 已上线条目新增车企或场景域，属于扩大生效范围，建议重新审批。

    

    

#### 2\.5\.3 检索注入侧

1. 当前请求必须携带车企/渠道、环境和场景域标识。

2. 检索服务先按生效范围过滤，再在候选池中做语义召回。

3. 赛力斯舱内请求只允许召回赛力斯舱内可见条目；赛力斯舱外同理。

4. 目标池为空时返回空动态示例并记录监控，禁止拿其他车企或其他场景域内容兜底。

5. 平台字段与检索过滤必须一起上线。只加页面字段、不改运行时过滤，不能算需求完成。
