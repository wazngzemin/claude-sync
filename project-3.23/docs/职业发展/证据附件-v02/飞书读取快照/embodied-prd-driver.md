# 1\. 概述



## 1\.1\. 需求背景

1. 豆包汽车1\.0 完成数字世界的Agent上车，让座舱具备了更加拟人、丝滑的交互体验，并能接管用户车控、导航、娱乐、生活服务等。

2. 舱驾融合重新思考和定义AI汽车的体验，让汽车成为像人一样思考\&amp;行动的物理司机的具身智能体。



## 1\.2 用户研究



1. 与11位网约车/专车司乘用户进行workshop，并与1位私家司机、2位Robotaxi深度用户进行1V1深度访谈；

2. 识别到从快车司机、专车司机、私人司机、Robotaxi出行服务中的痛点和诉求，几种不同类型的出行方式带来不同的出行体验，有巨大体验断层，这给司机Agent带来了差异化的机会点。

## 6\. 泊车场景 \(Parking Scenarios\)
