# R 章新增部件候选

对照全站现有 7 张卡片，合并同一职责的不同来源、保留车型实现选项后，得到 **27 组候选部件、35 条原始来源记录**。这不是已批准的新部件卡片；未改 component-cards.md。候选包含真实独立系统、职责逻辑和未闭环提案，不能从名称推定独立模型或进程。

每组第一条是主记录，后续是补充证据/车型变体；全部保留是什么、位置、输入、输出、关键数字和来源。卡片已包含的 ASR、1.7B、云端最终拒识、VAD、Planner、30B 与 TTS 模型不另建重复模型卡。裸文件名来源均在 `../chapters/R/raw/`，既有研究在 `../chapters/R/`。
