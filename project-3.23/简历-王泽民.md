## 工作经历

### 字节跳动 | AI 产品经理（豆包上车 · 智能座舱） | 【YYYY.MM】— 至今

负责上汽荣威量产车载 AI 助手的 Planner 模块与触发器产品。系统为三层漏斗架构：句法 RAG（毫秒级）→ 情景 RAG + 仲裁模型 → Planner（云端大模型深度推理），Planner 调度 20+ 个下游工具（车控/导航/音乐/搜索/记忆等），通过 tool_feedback 闭环跟踪执行进度。

#### 1. Planner：大模型任务规划中枢（产品 Owner）

- **系统提示词（SP）设计与治理**：管理约 3 万+ tokens 的 SP，涵盖工具定义、参考示例、车辆设备知识、情绪与话术风格等 10 大组件；主导 SP 实修方案（逐工具 before/after），修复媒体播控归属、记忆分类、并行工具互斥等高频易错点。
- **上下文优化**：设计"远区精简 + 近区完整"的对话历史压缩方案，历史 token 节省 40%–70%，总输入减少约 10%，实际计算量降低约 19%（Attention O(n²) 特性）。
- **Badcase 分诊体系**：自建 A–F 六类分诊框架（推理错误/幻觉/链路归属/责任方/能力边界/严重性误标），对 138 条 JIRA bug 批量定责 + 33 个典型 case 逐例分析，用数据证明约 35% 问题非 Planner 自身，将"模型能力问题"与"链路/上下文/工具描述问题"精准剥离。
- **根治方案推动**：定位"车端状态表格式模型读不懂"为最高频根因，推动端状态由表格改为自然语言描述（无需重训模型即修复一大类问题）；补充空间关系知识（"主驾右=副驾"方位映射）。
- **动态示例机制（检索增强）**：设计按场景检索注入 SP 的 query→决策对机制，用于快速修复 badcase；从首批近百条扩写至平台存量 1200+ 条；定义"一句话状态分支"写作规范（每条自包含、穷举真实车态信号分支）与"一族一解"防召回稀释原则。
- **评测体系**：定义评测口径与优先级标准——推理准确率 ≥90%、端状态理解 ≥93%、首 token P50 500ms / P90 800ms；与测试共建"缺失/冗余/错误"三 fail 字典。
- **管理平台需求**：推动动态示例管理平台二期，定义车企 × 环境二维隔离（防跨车型能力边界幻觉）、查重拦截、批量导出等 P0 需求。

#### 2. 触发器：事件感知 + 条件判断 + 动作执行引擎（产品 Owner）

- **产品定义与架构**：完成触发器从概念到量产 PRD 的产品定义——主动服务、动态 Advisor、条件任务共用的"感知订阅执行底座"；设计云端（注册校验/语义仲裁/模型类事件）与端侧（定时器/条件判定/离线闭环）两级分工；推动"编排归触发器、原料归信号中枢"的边界共识。
- **导航类事件 PRD**：主导"接近/到达/离开"导航触发需求，设计 one-shot POI 状态机（远→已接近→已到达→已离开，翻格自锁），解决"距离 <500m 每帧触发刷屏"问题；推动状态机放引擎 vs 端上计算的 A/B 方案决策。
- **语义触发（多模态）**：主导 VLM 视觉条件触发 PRD——定义 L1 语义匹配（caption↔明确目标）与 L2 泛化决策的职责边界；设计"枚举判定 + 防抖 + one-shot 边沿触发"策略，防误报防轰炸。
- **信号产品约束**：制定端状态上报的产品约束（格式/单位/示例），主动给出建议格式反喂研发，统一"剩余距离=整数米/时长=秒/到达时间=hh:mm"等口径，避免"带单位字符串 vs 数值比较"类链路错误。
- **端侧自闭环场景**：交付赛力斯"天气路况保护"场景（判定+执行不出车、断网可用）——雨/雪/雾三子场景规格、优先级仲裁（雪>雨>雾）、防抖策略（连续 3 周期 15s 一致才确认变更）、安全红线（超时不等于无雨）。
- **能力清单核对**：牵头场景需求 × 原子能力清单双向核对，发现并推动新增缺失积木（途经点变更事件、充电口盖状态上架等），堵住场景落地缺口。

#### 3. 端云协同与车控离线模型

- **车控离线模型（SFT FC）**：定义端侧小模型（51 函数协议）的白名单与仲裁策略——命中白名单端侧直执行、未命中云端优先、云端超时端上兜底；性能目标时延 ≤200ms、准确率 ≥95%。
- **三层漏斗边界**：梳理"缓存（50ms）→ 离线 FC（200ms）→ 云端大模型"的召回边界与性能分工，明确离线模型=体验快慢边界。

#### 4. 质量工程与效率工具

- 自建 JIRA 一键流转面板，自动化"分析→修复→完成"三步流转（含附件与评论），支撑 138 条 bug 批量分诊关单。
- 跨团队协作：与信号中枢、端上研发、VLM 视觉、配置平台、意图、测试等 10+ 角色持续对齐需求、边界与排期。
