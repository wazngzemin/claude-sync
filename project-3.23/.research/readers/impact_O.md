# impact_O — 播报展示和真实结果：资料有、副本可能缺的点

来源：d03 Director PRD v1.7、t08 S2S闲聊+端状态、t07 S2S对话工具、t20 S2S接入方案、t12 端状态&事件日志上报 One Page。

## 1. 对话内容策略细则（PRD 判例）
- 端状态问答/记忆问答/简单车控无需无意义首轮话术（bad："我帮你查一下"；good：直接答"空调现在是开着的"）。
- 首轮话术不能预设工具结果（bad："空调已调成24度啦"；good："我来帮你把空调调成24度"）。
- 首轮/次轮话术重复率低（good：次轮只说"都搞定啦"）。
- 第一个标点前内容尽量简短（为 TTS 快速合成）。
- 对话内容只能是文字+标点，不能用 emoji/表格/列表。
- 来源：https://bytedance.larkoffice.com/wiki/XRuKwJ0VPisdUhkxH0ecY1rRn9g【已确认 PRD】

## 4. 说出来 vs 显示出来 vs 真实状态：S2S 链路的新分流
- Planner 判联网/演绎 → 回调端侧拉 RTC，用缓存首轮语音走 S2S 端到端语音应答；识别到执行类指令立刻断联切回"文本→执行→TTS"链路；MVP 阶段多音区语音合并单路上行；不支持跨链路复合指令（"开窗并唱歌"优先执行部分）。
- 来源：https://bytedance.larkoffice.com/wiki/OngswPv99iudfekGoQycI18QnMd【已确认方案】

## 5. S2S 端状态话术口径（t08）
- 端信号只报名称+状态（删除描述），limit 50；【信号参数互斥】【当前状态优先】【未知信号如实回复】（不在信号列表就说不知道）；车控只"推荐询问"不直接执行（"太热了"→"需要我帮你打开空调吗？"）；拟人言语行为=思考停顿/连读/磕巴/倒装。
- 来源：https://bytedance.larkoffice.com/docx/MCLWdWAoQokmQtxlGAbcWDShn2e【已确认 SP 模板】
