3. C：冻结初始条件及变化规则，不冻结多轮 Context；动作受理、真实变化与状态回传必须分开。
4. M：空 answer 只能证明未记录到答复，不能直接认定拒识模型过拒，需沿正式文本、路由、接收、决策、播放查断点。
5. S：主动服务与“不动作”基线比较，不能以更高召回掩盖打扰、权限和驾驶风险。
6. O：业务运行、界面可见、车辆结果和口头说明分别验收；真实完成以外，还要记录用户额外纠错负担。
