本需求在云端条件触发器平台新增一条通知卡 Mock 链路：事件或信号满足配置条件后，Trigger 执行“豆包闪念卡” Action。Action 配置固定正文和动效标识集合，经 AIDV 服务的 Frontier 链路下发到端侧；AIDV 构造卡片时固定 Title.Title = ""，端侧复用现有系统通知卡展示。
卡片标题固定为空，正文为固定文本，无按钮、无交互回调；正文不带变量且不经过模型推理。
动效标识集合在本期仅作为协议字段透传，不包含动效资源管理、服务端渲染或 PHUD 图案平台化。

需求点提炼

核心链路：事件或信号 → 条件触发器判断命中 → 豆包闪念卡 Action → 固定正文与动效标识集合 → AIDV 内部 RPC → AIDV 固定空标题并构造 Widget → Frontier → 端侧通知卡。
端侧复用现有通知卡，无按钮、无交互回调；展示时长、消失方式、多卡排队和 TTS 打断策略待确认。
本期不接入动态推理、提示词、模板槽位、VLM caption 生成或 PHUD 图案资源配置。

方案选型
方案一
方案一：Trigger 直接接入 Frontier。优点是少一次 RPC；缺点是 aidv_trigger 需新增 SDK、连接配置、QoS、路由和错误处理，并与 AIDV 重复建设下行能力，协议与运维责任分散。
方案二
方案二：Trigger 调 AIDV 内部 RPC，由 AIDV 构造 types.Widget 并复用 SendNewWidgetMessage 下发。优点是符合现有依赖方向，复用已上线的 Widget 通道、QoS 与 TTL；缺点是增加一次跨服务调用，且在不改造发送函数返回值的前提下，Trigger 无法获知 Frontier 真实受理结果。
最终选型

选择方案二：Trigger 条件命中 → 豆包闪念卡 Action → SendNotificationCard RPC → AIDV Handler 固定空标题并构造 types.Widget → frontier.SendNewWidgetMessage → 复用 Frontier Widget 通道 → 端侧。
Trigger 负责条件、Action 和业务执行记录；AIDV 负责参数防御性校验、Widget 组装与下行调用。

IDL Widget 映射与发送（示意）
func (s *AIDVServiceImpl) SendNotificationCard(
    ctx context.Context,
    req *aidvtrigger.SendNotificationCardRequest,
) (*aidvtrigger.SendNotificationCardResponse, error) {
    if req == nil || req.GetCommonInfo() == nil || req.GetCommonInfo().GetDeviceId() <= 0 {
        return nil, errors.New("params err: common_info.device_id is required")
    }

    rpcWidget := req.GetWidget()
    if rpcWidget == nil || rpcWidget.GetWidgetData() == nil {
        return nil, errors.New("params err: widget and widget_data are required")
    }
    rpcData := rpcWidget.GetWidgetData()
    widgetRequestID := strings.TrimSpace(rpcData.GetWidgetRequestId())
    content := strings.TrimSpace(rpcData.GetContent())
    if rpcWidget.GetWidgetId() != types.WidgetIDDoubaoFlash ||
        widgetRequestID == "" || content == "" || strings.TrimSpace(rpcData.GetViewData()) == "" {
        return nil, errors.New("params err: invalid notification card widget")
    }
    
    // CustomKitex 已将 IDL common_info 写入 context；发送前再校验一次，
    // 避免 SendNewWidgetMessage 因取不到 device_id 而仅记录日志后返回。
    commonInfo, err := types.GetCommonInfoFromContext(ctx)
    if err != nil || commonInfo.DeviceID <= 0 {
        return nil, errors.New("rpc common_info is missing from context")
    }

    widget := types.Widget{
        WidgetID: types.WidgetIDDoubaoFlash,
        WidgetData: types.WidgetData{
            WidgetRequestID: widgetRequestID,
            Title: types.WidgetTitle{
                Title: "",
                Desc:  "",
            },
            ViewData: rpcData.GetViewData(),
        },
    }
    frontier.SendNewWidgetMessage(ctx, widget)

    return &aidvtrigger.SendNotificationCardResponse{
        WidgetRequestId: widgetRequestID,
        BaseResp:        base.NewBaseResp(),
    }, nil
}
