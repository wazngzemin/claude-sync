泽民（2026-07-30）自述时间管理痛苦：不知道下一步干什么→刷手机；需求表忘填；晚上忘复盘。诊断：他的《全部需求表.xlsx》是需求池不是日程表，系统缺"今日"层、无触发器、复盘是孤儿动作。

**方案（他自己就是做触发器的，用 Condition-Trigger-Action 语言）：**
1. 早到工位→5分钟从需求池捞"今日三件事"（至少1件是躲着的难事）
2. 手伸向手机→先扫工位便签（三件事+下一步动作），手机放够不着处
3. 合电脑→30秒三行复盘（做完几件/卡在哪/明天第一个动作）

**产物（均在 ~/Downloads/yx-files/）：**
- `全部需求表_管理版v1.xlsx`：原表加"今天/下一步动作/今日状态"三列 + 「今日三件事」sheet（打开即见，已预填建议；v2又加了时间块表+缝隙清单）+「每日复盘」sheet
- `个人时间管理_一日流程_v1.html`→`_v2.html`：可打印工位卡；v2=时间块时间轴+缝隙清单+窗口纪律+单线程4周训练

**v2升级（7/30当天第二次对话）：** 泽民说任务不止这些、晨读AI资讯/中午看别的/等AI生成时注意力被拉走/窗口多就切走/多线程成瘾不会单线程。v2方案=时间块（晨读只判级不当场挖/上午深工放最难件/午间给合法名分/下午浅工集中回消息）+缝隙清单接微等待+窗口纪律（每块全屏/中午大清）+计划内切换概念+25→40→60分钟渐进单线程训练。

**v3定版（7/30第三次对话）：** 泽民反馈"填表麻烦，一麻烦就不填，要最小成本"→ 系统改为[[feedback_morning_review_protocol]]：他只做两件事（发"早"/发"复盘"+手写便签），Excel退化为Claude读的仓库，记录写到 `~/Desktop/时间管理_记录.md`。v3卡=`个人时间管理_一日流程_v3.html`（明日逐时刻脚本+便签画法）。教训：给他设计的任何系统，先数他要几步操作，超过2步就会被弃用。

**后续反复（7/30当天）：** 他否决"早/复盘"协议（"不是要让你给我做事情"）→ 自选飞书日历+任务+文档 → 要详细模板（飞书每日账本模板v1/v2：青蛙+优先级P0P1P2+📦没做完去处+小贴士）→ 又批"太散了，不是来作秀的"→ 极简v3又批"瞎编，去找网上别人用的"→ 找到飞书官方模板拆解 → 他最终拍板要"**文档中带表格**"形式 → 迭代出 `飞书每日计划文档模板_表格版_v1~v3`：v1=纯工作两表，v2=加回晨读输入/✅做成了/五个场景小贴士附录，**v3=并入体检方案**（`/Desktop/3.23/体检报告国际专家解读-v2.html`：尿酸466.7/易腹泻/久坐/压力大；每日区块加表4健康打卡6勾：水2L/三件套/每小时起身/无奶茶油炸/快走/12:30前睡；附录B健康执行卡=补剂三件套+三餐模板+忌口+复查时间轴8月中下旬；复查进表1当P1任务）。教训：①他要"详细"时要的是**单点写透**不是板块堆多；②别自己发明模板，先找有出处的真实模板再裁剪；③每天要填的必须极少（打勾>写字），参考资料放附录只看不用填。

**Why:** 核心洞察=刷手机发生在"任务太大太模糊需现场决策"的缝隙；"下一步动作"列（动词开头、10分钟可启动）是治本。
**How to apply:** 后续若他说又坚持不下来，先问哪个触发器断了，别加新规则；升级方向=每周回顾、难事占比。
