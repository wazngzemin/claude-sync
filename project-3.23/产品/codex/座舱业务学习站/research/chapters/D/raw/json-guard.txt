输出优化保障(二)
背景
在上述优化做完以后，做到100%模型输出json合法，并且100%模型输出json字段和层级符合预期，但是有新的问题出现
image.png

模型输出的json顺序不确定了，会概率性如图所示，这样会有2个问题：
1.tts的文本晚了，首token不变，但是首字晚了，会有延迟体感
2.强依赖这个输出json字段顺序的功能，aibot，会影响功能
3.由于模型有学习历史对话，后面的会学习，会加大顺序不符合预期的概率
问题排查
image.png

做了几组实验，1.8的顺序是好的，那就是2.1-turbo有特殊之处。
继续和方舟同学沟通，传入的json_schema用了golang的map，而map本身是无序的，问题应该就在于这里：
image.png

结论，用struct来重写json_schema
优化改动
json_schema
用struct来重写json_schema，注意Properties字段，如下：

arkParams := doubao.ArkModel{
    ModelConfig: ark.ChatModelConfig{
       //ServiceTier: thrift.StringPtr("fast"),
       Timeout: pkg_util.PtrIfNotZero(time.Second * 60),
       ResponseFormat: &ark.ResponseFormat{
          Type: model.ResponseFormatJSONSchema,
          JSONSchema: &model.ResponseFormatJSONSchemaJSONSchemaParam{
             Name:   "planner_text_output",
             Strict: true,
             Schema: struct {
                Type                 string   `json:"type"`
                Properties           any      `json:"properties"`
                Required             []string `json:"required"`
                AdditionalProperties bool     `json:"additionalProperties"`
             }{
                Type: "object",
                Properties: struct {
                   TalkOrNot   any `json:"talk_or_not"`
                   TalkContent any `json:"talk_content"`
                   EmojiID     any `json:"emoji_id"`
                   ActionList  any `json:"action_list"`
                }{
                   TalkOrNot: map[string]any{"type": "string"},
                   TalkContent: map[string]any{"type": "string"},
                   EmojiID: map[string]any{"type": "string"},
                   ActionList: map[string]any{
                      "type": "array",
                      "items": struct {
                         Type                 string   `json:"type"`
                         Properties           any      `json:"properties"`
                         Required             []string `json:"required"`
                         AdditionalProperties bool     `json:"additionalProperties"`
                      }{
                         Type: "object",
                         Properties: struct {
                            ActionID any `json:"action_id"`
                            ToolName any `json:"tool_name"`
                            Params   any `json:"params"`
                         }{
                            ActionID: map[string]any{"type": "string"},
                            ToolName: map[string]any{"type": "string"},
                            Params: map[string]any{"type": "object", "additionalProperties": true},
                         },
                         Required: []string{"action_id", "tool_name", "params"},
                         AdditionalProperties: false,
                      },
                   },
                },
                Required: []string{"talk_or_not", "talk_content", "emoji_id", "action_list"},
                AdditionalProperties: false,
             },
          },
       },
    },
    Messages:              state.Messages,
    Channel:               chatReq.CommonInfo.Channel,
    FunctionKey:           ark_config.FuncPlannerAnalyzeText,
    SystemPromptVariables: systemPromptVariables,
    SPHardening:           true,
}
