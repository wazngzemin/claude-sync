> Query：“记下我家是麦当劳”“设置我公司是漕河泾B座”“修改我家地址为肯德基”
> 
> 

**核心原则：记忆写入位置信息时需包含****POI名称****，包含时可直接写入记忆，不包含时需借助POI search工具明确POI名称**

- 方案一：DT判断是否包含核心信息，不包含先调POI search工具（输入query导航去XXX），获取POI name\+城市名 后再调记忆工具，包含则直接调记忆工具

【不包含】query\-dt\-poi tool\-dt\-记忆tool【包含】query\-dt\-记忆tool

- 方案二：DT直接调记忆工具，记忆工具判断是否包含核心信息，不包含则记忆工具调POI search工具补全后记忆，包含则直接记忆

【不包含】query\-dt\-记忆tool \&lt;\-\-\&gt;poi tool 【包含】query\-dt\-记忆tool

- 方案三：DT直接调记忆工具，DT靠记忆工具msg返回判断是否需要调POI search工具补全信息

【不包含】query\-dt\-记忆tool\-dt\-poi tool\-dt\-记忆tool：记忆工具返回msg“需先输入query导航去XXX调POI search工具，用户选点后，获取详细POI名称后再记忆”【包含】query\-dt\-记忆tool

### 座椅记忆策略

#### 保存逻辑

用户（主驾\&amp;副驾）上车 → 调整座椅位置 → 中控屏弹窗提示保存 → 用户保存

> Face id\&amp;账号切换逻辑：
> 
> - 若A注册了face id并存在关联账号，主驾A上车后会自动切换A的账号
> 
> - 若车机已登录账号A，B注册了face id并存在关联账号，主驾B上车后会自动切换B的账号
> 
> - 若车机已登录账号A，B未注册face id，主驾B上车后A账号不会退登
> 
> 

#### 保存查看与切换

主驾侧/副驾侧下拉栏块控图标，点击显示3套座椅位置，点击后直接执行对应座椅位置切换

#### 用户编辑

可选择编辑当前座椅位置的名称
