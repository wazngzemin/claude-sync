目标

整合用户query、context、tool，基于 React 范式，实现具备复杂推理的、个性化的播客服务。

  1. TOOL能力封装：为主动服务及planner提供工具调用能力，丰富context，提升推理能力及服务效率
  1. AI播客交互：针对部分AI播客服务，需提供单独AI播客卡片承载交互。（例如“planner通过FC调用SDK的单/多接口或喜马拉雅agent能力后，AI播客交互卡片承载信息”）
  1. 支持复杂推理构建：支持 query+context+tool+语音链路的整体端到端能力，能够根据需求自主抽取context信息并调用tool，达成复杂推理，提升服务准确率。

AI播客agent描述和tools清单

实时生成播客Agent工具描述

1、中文名称
实时生成播客
2、英文名称
realtime_podcast_agent
3、功能描述
面向车载收听场景的实时播客内容生成 Agent，基于用户给定主题或当下热点，自动生成可播报的轻量播客音频稿，适用于新闻速览、热点解读、趋势分析与主题电台类内容。
 该 Agent 不依赖固定音频平台资源，核心价值在于“即时生成 + 即听即走”。
4、请求时 Query 的描述
用户希望即时获取某一主题的播客化解读或生成音频内容的指令，如如：‘把这条新闻做成一段播客’、‘生成AI主题的播客’、‘用轻松一点的播客风格聊XX’、‘做一期解读XX的节目’、‘用电台的方式说说XX’、‘帮我做一期关于XX的播客’、‘把XX整理成一段语音节目’、‘模拟一段播客讲XX’热点新闻播报、主题播客创作、电台式讲解等。
注意：不支持搜索或播放平台已有播客。
