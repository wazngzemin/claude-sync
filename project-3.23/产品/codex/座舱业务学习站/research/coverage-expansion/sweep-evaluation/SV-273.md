# 座舱大模型产品双周会\-20240731

<div class="callout">

- 周会目的：

1. 各组/各项目信息同步、组间资源协调、风险预警



- 会议议题：

1. 销售/行解团队同步商务进展

2. 产研各团队同步双周进展、下双周计划、风险预警和组间求助

3. 专项议题提出

4. 待办事项跟进



- 会议时长：90 mins



- 会议流程：

1. 会前：各组补充本组信息到周报文档中

2. 会中：前20分钟，阅读会形式，参会人员针对文档进行评论和解答；

3. 会中：第21\~80分钟，串讲及评论讨论；

4. 会中：第80\~90分钟，快速同步代办事项，明确专项TODO（各owner线下讨论）
