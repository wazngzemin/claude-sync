泽民嫌填表麻烦（一麻烦就不填），2026-07-30 最终定版：**飞书三件套**——飞书日历（9:25定三件事+17:50复盘，两个重复日程主动弹窗）+ 飞书任务（三件事勾选）+ 飞书文档「每日账本」（倒序，每天四行：✅今天做成了/🧱卡在哪/➡️明天第一件事；文档链接粘进17:50日程描述里）。

**否决过的方案（别再推荐）：** ①Claude"早/复盘"两字协议——他说"我不是要让你给我做事情，你做的也不好，你不知道我今天要做什么"；②Excel管理表——嫌填表麻烦。教训：给他做时间管理系统，工具必须能主动找他（弹窗/提醒），一切等他来打开的都会死；且他要的是自己掌控，不是AI代劳。

**Why:** 打开Excel→找sheet→点单元格→打字 = 4-5步摩擦，每步都是放弃点；他每天反正开着Claude Code，口头交互成本最低。

**How to apply:**
- 他若反馈系统又断了，先问断在哪一环（日历提醒没建/任务没勾/文档没写），只修那一环，不推新工具、不推Claude代劳
- 白天专注法（缝隙清单/窗口纪律/全屏单块）依然有效，但只在他主动问起时再提
