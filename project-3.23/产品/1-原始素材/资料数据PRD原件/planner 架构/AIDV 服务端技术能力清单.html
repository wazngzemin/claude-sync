前置依赖

说明

租户与身份体系

统一租户、应用、车辆和账号的归属与授权关系，让请求、后台任务及回调都能确定所属租户和用户身份，为配置选择、资源使用、权限校验和业务数据隔离提供依据。缺少这层，业务无法可靠地按租户执行不同策略。

租户配置与资源管理

统一管理各租户的能力开关、业务参数、资源绑定与额度，支持平台默认值、租户覆盖、依赖校验、配置生效和回滚。业务通过统一方式读取并执行配置，变更只影响目标租户；账号层承载个人偏好与授权设置。例如，记忆的开关、保存策略和资源选择属于配置，具体记忆内容由业务按归属和权限管理。

统一接口与适配机制

统一能力调用、事件与结果反馈协议，提供接口文档和示例。端 SDK 与云端使用已对齐的协议；客户云云服务按我方协议完成接入。已有能力通过注册、资源绑定和参数配置开通，复用云端调用与结果处理。

技术能力清单

按现有能力和我方统一协议评估。端 SDK 与云端已完成协议对接；客户云云服务按我方接口、事件和结果协议接入。

现有能力基础：

  • 已支持＝可直接复用或经现有配置开通；

我方工作只列确定的配置或开发事项，无需处理时留空。
