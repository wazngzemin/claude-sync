节点 1

供应商：思必驰端侧实现

功能：
• 5/6音区识别（主驾/副驾/二排）

节点 3
⏱ VAD 语音活动检测
三级判停机制：

Soft VAD 300ms
→ 预请求 /aidv/v1/pre_query
→ 拒识+Context前置
→ 不进对话历史

Hard VAD 600ms
→ 正式请求
→ 结束ASR，发送完整query

语义VAD 1000ms
→ 延长收音（待评审方案）
节点 4
🗣 ASR 语音识别
双遍识别策略：

一遍：流式partial（实时）
• 供实时判断/抢跑
• 可能有识别误差

二遍：非流式final（正式）
• 正式Query文本
• 更高准确率

性能指标： 在线首字≤200ms 在线尾字≤500ms 离线车控≥90%
节点 5
🔍 拒识判断
目标：区分对车说话 vs 人人闲聊

机制：
• 句法RAG拦截
• SimpleIntent模型
• 在Planner前规则级过滤

结果：
✅ 对车说话 → 继续处理
❌ 人人闲聊 → 不回应

🔥 核心架构：三层漏斗分流机制
设计理念：用户请求不是全部走最重的 Planner 推理，而是按复杂度智能分三层处理，实现性能与质量的最佳平衡。

分流原则：
• 第一层：简单明确指令 → 毫秒级规则匹配 → 极速响应
• 第二层：需要上下文 → 注入Context → 快速判断
• 第三层：复杂需求 → 云端LLM深度推理 → 多步规划
第一层
句法 RAG（毫秒级）
处理范围：明确简单指令
• "打开车窗"
• "空调最大"
• "关闭天窗"
• "播放音乐"

处理方式：
• 规则级拦截
• 直接调用车控工具
• 不进Planner推理

优势：
极快响应 准确率高 资源消耗低
第二层
情景 RAG + 仲裁模型
处理范围：需要注入上下文
• 用户记忆（不喜欢紫色）
• 车况状态（空调当前温度）
• 环境信息（外面下雨/气温）
• 乘员信息（副驾在睡觉）

处理方式：
• 注入Context场景信息
• 判断简单/复杂分流
• 简单的快速执行
• 复杂的转第三层

Context注入内容：
{{env_info}} {{memory}} {{status}} {{goal_list}}
第三层
Planner 深度推理（云端LLM）
处理范围：复杂需求
• "有点热又有点闷还想听点提神的"
• "去昨天的游泳馆"
• "找个不堵车的路线"
• "10分钟后关座椅加热"

处理方式：
• 多步规划（最多20步）
• 调度多工具（23个工具）
• 跟踪进度反馈
• ReAct闭环推理

底层模型：
豆包 Seed 1.8 云端部署

输入规模：
SP ~30K tokens UP ~10K tokens
简单指令快路径
需要上下文
复杂需求
节点 7
📦 Context 场景准备
预注入数据（覆盖80%）：
• {{env_info}} 车辆状态
• {{memory}} 用户记忆
• {{status}} 视觉感知
• {{goal_list}} 目标队列

不足时（20%）：
• Planner调检索工具
• 按需兜底补充

性能： 平均 ~550ms
节点 8
🧠 Planner 推理引擎
技术架构：
• 框架：Eino ReAct图
• 模型：豆包 Seed 1.8
• 部署：云端
• 最大步数：20步

SP（~30K tokens）包含：
• 角色定义 + 23个工具定义
• 69个参考示例
• 10条注意事项
• 车辆设备知识(D6X)
• 聊天风格(温柔高知女生)
• 动态模板变量

UP（~10K tokens）包含：
• 最近N轮对话历史
• 当前query + advisor建议

性能： 首token ~1300ms

节点 10
🔧 Agent Server 工具调度
职责：工具执行适配层

支持6类AgentType：
• AIDV：座舱云内部服务
• DPFM：车控执行
• Doubao：豆包能力
• Ecology：三方生态服务
• Offline：端侧能力
• InternalRPC：内部RPC

策略：
• 并行执行：独立工具
• 串行执行：有依赖
• Redirect限制：≤2次
• 超时保护 + 失败重试3次

节点 12
📤 工具反馈处理与循环判断
每个工具返回 tool_feedback：
• 执行状态：success / failed
• 结果数据：具体返回值
• 错误信息：失败原因

Agent Server合并：
• mergeToolOutputs
• 回灌成observation
• 继续喂给Planner

Planner循环判断：
• action_list非空 且 step < 20
  → 继续调用tools节点
• 否则 → direct_return
• ReAct闭环推理
