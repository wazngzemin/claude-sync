# 二、AI汽车主线**交互**

### 范围

**语音交互：**新增多音区免唤醒；

**任务岛：**AI Doc栏\+任务；潜在的用户需求，则需要一个副入口，方便用户快速去对当前潜在的需求进行交互，以持续任务和AI推荐任务的形式展现，另外将过去的dock栏（应用中心、桌面这些内容）进行合并。

**Planner：**包含用户Query和主动推荐任务，同时会分类持续/条件任务和即时任务；

**豆包Agent**：联网、音乐（汽水）、车书、视频、POI、车控、提醒、AI navi、
