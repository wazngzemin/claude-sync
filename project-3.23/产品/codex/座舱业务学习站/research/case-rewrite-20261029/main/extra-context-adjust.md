# Director上下文调整\-需求说明

**调整需求**



**差异说明：**

- **1 最新的用户query需要增加context变量**

    - 意义：经验证，能有效增强director对context的使用能力，同时并不会导致过度的context参考

    - 具体要求：

        - Context包含【goal\_list】——目标，【env\_info】——端状态，舱内外视觉和用户记忆则依然放在sp里

            ```R
            ## 当前目标队列：
            这是你当前在持续追踪的目标list，包含每个目标的内容、目标的进展
            <当前目标队列信息>
            {{goal_list}}
            </当前目标队列信息>
            
            ## 车辆状态：
            整个车的状态，包含空调、座椅、驾驶、导航、媒体娱乐等各类车辆的最新状态信息，注意这是最新的车辆状态信息！相比于对话历史你要优先参考这里的信息，是更新更准确的。
            <最新车辆状态信息>
            {{env_info}}
            </最新车辆状态信息>
            ```

        - 另外成为历史后，不再保留context变量，以节省上下文窗口

- **2 历史中新增工具返回的后director的播报和执行**

    - 意义：让director有更清晰的近期工具使用记忆，更有利于有逻辑的任务推理效果

    - 具体要求：

        - 完整保留工具返回的input以及工具返回后的豆包播报和豆包执行

- **3 历史中新增用户query输入时豆包的执行输出**

    - 意义：让director有更清晰的近期工具使用记忆，有利于有逻辑的任务推理，同时有利于问题/bug分析

    - 具体要求：

        - 有完整tool调用输出

- **4 用户query时增加时间戳\+上次query间隔时间**

    - 意义：让director能对时间有一定感知力

    - 具体要求：

        - 当前的时间戳，方式可以\[年/月/日\-时:分:秒\]，如\[\[2026/5/18\-14:32:28\]

        - 上次query间隔时间，统计同一user的时间差，3分2秒

            - 若为非注册用户，则根据位置统计query时间差

            - 若为注册用户，根据身份统计query时间差
