## D5｜拍板量产资源与时效红线

### 资源参数

| 参数 | 含义 | 本次数字 | 数据来源/DRI |
|---|---|---|---|
| `F` / `e` | 能力车总量 / 开启率 |  |  |
| `Vpeak` | 峰值活跃车辆 |  |  |
| `T` / `Δ` | 每车任务数 / 视觉包间隔 |  |  |
| `r` / `k` | 慢路包比例 / 每次判断的模型调用数 |  |  |
| `h` | 每车每日活跃小时 |  |  |
| Token/单价 | 每次输入输出及每百万 Token 单价 |  |  |

统一公式：

```text
A 日调用 = F × e × h × 3600 ÷ Δ × T × k
B 日调用 = F × e × h × 3600 ÷ Δ × k
C 日调用 = F × e × h × 3600 ÷ Δ × r × k
单次成本 = (Tin × Pin + Tout × Pout) ÷ 1,000,000
```
