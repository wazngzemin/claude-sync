## 搜索不是全文阅读

两个全分页元数据结果分别为 176 条与 575 条去重命中，集合重叠，且 Reflector 命中大量非汽车内容。不得相加成“已读汽车文档数”。其他主题检索仅展开部分相关正文。所有搜索 JSON 保留供核验。

Reflector 会议检索成功返回空列表；这只说明本次查询未命中。没有将“未检索到”写成“没有实现”。汽车服务端周报因长度截断，仅取得前部，不据此推断 MVP 全机制。
