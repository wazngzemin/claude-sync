# 02｜端侧天气保护业务流程

类型：自上而下业务流程图；23 个节点；画布 680 × 3104。

- TC：用户在任务中心开启天气保护；任务中心转发开启操作；不直接切驾驶模式。位置 (90,170)，尺寸 350×66。
- ENABLE：天气任务接入方处理真实开启；保存结果，返回任务中心，并让本地触发器可读取；开关状态如何同步、具体由谁承接：待会签。位置 (90,292)，尺寸 350×84。
- DATA：端侧触发器收到相关数据更新；赛力斯提供：车速、驾驶模式等真实车况；字节视觉能力提供：天气／路面结构化识别结果；相关条件更新后重新判断，不只等天气变化。位置 (90,432)，尺寸 350×106。
- VALID：任务有效且数据可用吗？；状态不明、识别过时都不能当满足。位置 (90,594)，尺寸 350×124。
- WAIT：暂不发起建议；不开卡、不车控；等待有效更新；任务关闭则停用。位置 (510,594)，尺寸 130×124。
- RULE：触发器检查这条湿滑建议的规则；天气下雨／路面湿滑，且车速大于30 km/h；驾驶模式还不是湿滑；识别稳定、本次没有重复；并且／或者、稳定与频控参数：按评审结论落地。位置 (90,792)，尺寸 350×106。
- HIT：场景规则全部满足吗？；例：车速46，仍下雨，普通模式。位置 (90,954)，尺寸 350×124。
- NOTYET：继续等待更新；例：下雨但车速20；此时不出卡；之后车速满足再判断。位置 (510,954)，尺寸 130×124。
- ASKDEF：天气任务业务准备本次询问；告诉卡片：建议切湿滑模式；确认／取消按钮；提供播报文本、允许的按钮表达、建议有效范围；说明这次询问对应哪个任务、哪个建议。位置 (90,1134)，尺寸 350×106。
- CARD：天气业务请求本地即时交互卡；卡片负责接收、按优先级排队、展示和反馈；此处不经过 Planner；请求受理不等于已显示。位置 (90,1318)，尺寸 350×84。
- SHOWN：卡片已真正展示了吗？；仍在排队时，不能当作用户已看见。位置 (90,1458)，尺寸 350×124。
- QUEUE：未展示：等待；轮到且有效再显示；过期、失败或任务关；撤销本次，不车控。位置 (510,1458)，尺寸 130×124。
- VISIBLE：车机展示“是否切换湿滑模式？”；确认／取消按钮；按语音策略播报提示文本；卡片接入方注册当前按钮词，结束时注销；禁播音／禁识别的降级方式需交互团队确认。位置 (90,1640)，尺寸 350×106。
- CLICK：用户手动点击；确认／取消原按钮；直接触发原按钮处理。位置 (50,1820)，尺寸 260×124。
- VAS：用户说出支持的按钮表达；可见即可说：语音匹配当前按钮；语音能力返回命中的按钮；注册方模拟同一个原按钮点击。位置 (370,1820)，尺寸 260×124。
- CHOICE：天气业务收到本次交互结果；确认或取消；关联当前这一次有效询问；卡片另行反馈关闭／超时／被替换等生命周期；同次点击与语音只处理一次，不直接重复车控。位置 (90,2020)，尺寸 350×106。
- YES：是这次有效的确认吗？；当前询问未过期，且尚未处理。位置 (90,2182)，尺寸 350×124。
- NO：未获有效确认；取消／关闭／超时；旧卡／重复回应；结束本次，不执行。位置 (510,2182)，尺寸 130×124。
- PRE：最新任务和车况仍允许吗？；任务未关、建议有效、车辆允许。位置 (90,2382)，尺寸 350×124。
- ABORT：取消本次执行；条件已变／已处理；返回未执行原因；不重复发车控。位置 (510,2382)，尺寸 130×124。
- EXEC：天气执行业务请求切换湿滑模式；端侧执行逻辑调用赛力斯车控；“收到请求”仅是过程，尚不能报切换成功。位置 (90,2564)，尺寸 350×84。
- READ：读取当前真实驾驶模式；实际已是湿滑：成功；明确失败：失败；无法获取可信状态：暂不能确认成功。位置 (90,2704)，尺寸 350×84。
- RESULT：天气业务把真实结果交回卡片；卡片显示本次成功／失败／暂不能确认；结束本次，取消旧确认按钮词，按规则继续等待；用户取消这次建议，不等于关闭天气保护。位置 (90,2844)，尺寸 350×106。

箭头：TC → ENABLE（开启操作）；ENABLE → DATA（真实有效状态）；DATA → VALID（当前数据）；VALID → WAIT（否）；VALID → RULE（是）；RULE → HIT（逐项判断）；HIT → NOTYET（否）；HIT → ASKDEF（是）；VISIBLE → CHOICE（关闭／超时）；ASKDEF → CARD（本次询问内容）；CARD → SHOWN（展示状态）；SHOWN → QUEUE（否）；SHOWN → VISIBLE（是）；QUEUE → VISIBLE（可展示）；VISIBLE → CLICK（手动）；VISIBLE → VAS（语音）；CLICK → CHOICE（原按钮结果）；VAS → CHOICE（同一按钮结果）；CHOICE → YES（核对用户选择）；YES → NO（否）；YES → PRE（是）；PRE → ABORT（否）；PRE → EXEC（是）；EXEC → READ（车辆处理后）；READ → RESULT（实际结果）。
