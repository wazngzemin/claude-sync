参数解释


字段名

字段类型

字段解释

report_type

string

上报类型：
full：上电后的全量上报
update_all：部分信号的完整上报（struct结构里每个字段都是上报）
update_item：部分信号的局部上报（struct结构里部分字段上报）
delete：删除单个信号

signal_states

array

数组里是多个信号，每个信号需要有信号id、信号值、信号变化时间

signal_id

string

信号id，使用产品定义的端状态表格中的信号id

value

struct

单个信号值，里面的key是信号id，value是信号内容

vehicle.bodyaccess.door
不同信号这里字段名不一样，使用信号id的值

int、string、bool、float、struct、array之一

信号值内容，具体格式参照产品定义的表格

event_ts

int

信号变化时间，毫秒的时间戳
响应

{
    "succeed_ids": ["nav.favorite.lists"],
    "failed_id_to_msg": {
        "nav.favorite.listss": "SIGNAL_NOT_FOUND"
    }
}
参数解释


字段名

字段类型

字段解释

succeed_ids

array

上报成功的信号id

failed_id_to_msg

map

上报失败的信号id及其对应的错误码
错误码


错误码

错误原因

SIGNAL_NOT_FOUND

端状态信号id不存在

SCHEMA_MISMATCH

端状态格式不正确，与定义不一致

VALUE_KEY_MISMATCH

端状态值中的信号id不对

TOO_QUICK

该端状态上报得太过频繁

OUT_OF_ORDER

该端状态变化时间早于上一条

SYSTEM_ERROR

服务系统异常

CASCADE_FAILED

级联规则执行失败

UNSUPPORTED_FIELD

值中包含信号定义不支持的字段

VALUE_NIL

字段值为空（nil）

FIELD_REQUIRED

必填字段缺失

TYPE_MISMATCH

值类型与信号定义不匹配

FIELD_NOT_FOUND

信号定义的字段在值结构体中不存在

ENUM_MISMATCH

值不在枚举范围内

RANGE_OUT_OF_BOUNDS

数值超出允许范围
