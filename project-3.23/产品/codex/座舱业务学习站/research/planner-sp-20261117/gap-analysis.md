# 当前线上 Planner SP 与学习站差异分析

研究范围：用户于 2026-11-17 提供的赛力斯 AIVA ME7 在用 SP；只对照指定 Markdown 正文、全站卡片及项目说明。线上版本身份来自用户说明，未另行查询运行环境。

定位约定：`SP:Lx–Ly` 指同目录 `planner-sp.md` 的物理行号；章节路径均相对 `座舱业务学习站/`。原句只摘足以定位的短句。每条建议仅用于后续修订，本次不修改正文或网页。

判定口径：A 代表性正确；B 明确的旧口径/错误或未限定车型版本的现行断言；C 重要规则未覆盖或缺少可操作解释；D 为 SP 内部冲突与缺陷。历史设计与当前车型差异不能直接判错，SP 未描述的架构也不等于不存在。SP 规则与示例冲突时，不自行认定其中一个代表真实运行行为。

研究已完成：SP 全部 2,979 行逐行阅读；重点 D/C/E/F/T/M/K 按指定正文核对，其余 V/R/I/W 及 74 张卡片以关键字定位并回读相关段落。两份产出均分批写入；统计与高优先级索引见文末。
