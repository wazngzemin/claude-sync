另一台 Mac · 首次设置
====================
这个 App 是启动入口，单独复制 App 不包含同步程序和数据。
同步内容：Claude 配置、技能、插件、项目记忆，以及 ~/Desktop/3.23 工作文件。
不包含：Claude 聊天记录、账号登录状态、软件与依赖安装。

1. 准备 Git、Python 3、rsync；终端运行 git --version、python3 --version、rsync --version 检查。
2. 确认另一台电脑可访问 GitHub 私有仓库 wazngzemin/claude-sync。
   SSH 登录凭证不会随 App 迁移，需要在这台电脑配置有权限的 SSH 密钥。
   HTTPS clone 不保证自动打开浏览器；需先配置 GitHub CLI / 凭证管理器登录，或使用有效的访问令牌。
   不要在命令或截图里公开令牌。
3. 如果 ~/.claude-sync 不存在，在终端运行：
   git clone git@github.com:wazngzemin/claude-sync.git ~/.claude-sync
   已配置 HTTPS 凭证的用户也可用：
   git clone https://github.com/wazngzemin/claude-sync.git ~/.claude-sync
   如果目录已存在，不要删除或覆盖；先确认其中是否有 .git 和需要保留的文件。
4. 完整克隆成功后运行：
   bash ~/.claude-sync/安装.command
   这会拉取、分发文件并创建桌面 App。被覆盖的文件备份在 ~/.claude-sync-state/pull-backup.*。

以后同步
--------
办公室推送成功后，另一台电脑运行：
   bash ~/.claude-sync/家里-一键拉取.command
或通过桌面同步管理 App 拉取。
仓库已最新也会重新分发到实际目录；拉取失败会停止，不会将旧数据继续安装。

常见报错
--------
Permission denied / Authentication failed：当前机器尚未获得仓库访问权。
Could not resolve host / Connection timed out：网络或代理连接失败。
目标目录已存在：不是登录问题，不要重复 clone 到同一个目录。
本地修改会被覆盖 / 无法快进：两台电脑存在不同修改，先保留修改并处理差异；不要强制重置。
拉取是合并文件，不删除本机独有技能；同名文件可能被更新，原文件可从备份找回。
