7.6 单次业务状态机

长期任务的“开启 / 关闭”与一次业务运行不是同一个状态。长期任务保持开启时，可以经历多次独立停车事件；一次事件结束后，只清理该次建议和授权，不自动关闭长期任务。

    等待场景 --> 候选检查: 收到新的非P到P事件

    待注册卡片 --> 卡片排队: 原业务注册成功但暂不能展示
    待注册卡片 --> 卡片已展示: 可立即展示
    卡片排队 --> 卡片已展示: 轮到且建议仍有效
    卡片排队 --> 无动作结束: 任务关闭 / 场景失效 / 建议过期
    卡片已展示 --> 已授权: 当前用户明确确认
    卡片已展示 --> 无动作结束: 拒绝 / 关闭 / 超时 / 不明确
    已授权 --> 端侧复核: 原业务发出一次执行请求
    端侧复核 --> 无车控结束: 最新条件不允许 / 已经处理 / 授权过期
    端侧复核 --> 执行中: 复核通过并调用车控
    执行中 --> 成功: 真实口盖已打开
    执行中 --> 失败: 明确未达到或车控拒绝
    执行中 --> 暂不能确认: 缺少可信回读或观察超时
    无动作结束 --> 本次关闭
    无车控结束 --> 本次关闭
    成功 --> 本次关闭
    失败 --> 本次关闭
    暂不能确认 --> 本次关闭
    本次关闭 --> 等待场景: 长期任务仍开启
    本次关闭 --> [*]: 长期任务已关闭

执行中车控请求已发出等待车控结果和真实状态成功、失败或观察超时
本次关闭本次所有上下文已清理留痕；长期任务仍有效时等待下一次新的独立场景到来

任务关闭的统一规则：停止产生新事件；撤销未展示或待确认内容；旧点击、旧语音和旧授权失效；已发出的车控不假装已撤销，而是继续读取真实结果并按单项策略收口。
