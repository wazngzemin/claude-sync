# 01｜系统预设任务总业务流程

类型：自上而下业务流程图；28 个节点；画布 680 × 3240。

- P：字节产品＋赛力斯需求方；写清场景、触发条件、交互方式、车辆动作；同时写清：何时不处理、怎样算成功、何时再触发。位置 (90,170)，尺寸 350×84。
- CAP：各能力团队确认能否承接；信号／识别、触发器、任务中心、卡片／语音、车控；确认各自提供什么、交给谁、还缺什么。位置 (90,310)，尺寸 350×84。
- OK：关键能力接齐了吗？；每一段有人接、规则可执行。位置 (90,450)，尺寸 350×124。
- GAP：未齐：先补缺口；补信号或功能；明确承接团队；补齐后再检查。位置 (510,450)，尺寸 130×124。
- PUB：配置／端侧研发完成接入与发布；任务中心拿到：名称、说明、开关、操作接收方；运行方拿到：条件、后续处理、交互与结果要求；现状：云端配置已有能力；端侧仍有按需求开发。位置 (90,630)，尺寸 350×106。
- TC：任务中心展示任务；用户开启或关闭；展示内容来自任务接入方；把“哪项任务、要开还是关”交给指定接入方。位置 (90,816)，尺寸 350×84。
- BIZ：任务接入方处理启停并保存真实状态；真正使任务生效／停用，再反馈成功或失败；天气／充电由谁承接这段：待研发认领。位置 (90,958)，尺寸 350×84。
- UI：任务中心回显；按真实结果；更新开关状态；失败不显示成功。位置 (510,958)，尺寸 130×106。
- ON：任务已有效开启吗？；触发器拿真实状态，不读按钮颜色。位置 (90,1108)，尺寸 350×124。
- OFF：关闭／状态未知；不启动新处理；撤销未执行建议；恢复真值后再判断。位置 (510,1108)，尺寸 130×124。
- ROUTE：按任务定义选择判断链路；端侧／云端说的是处理位置，不是公司归属；所需规则和后续能力须已接入；不随网络随意切换。位置 (90,1306)，尺寸 350×84。
- EDGE：端侧触发器；读取本地车况和视觉结果；检查场景条件、数据可用、防重复；例：天气保护。位置 (50,1460)，尺寸 260×106。
- CLOUD：云端触发器；读取已上行的状态；检查启动条件、时效、防重复；例：充电前置条件。位置 (370,1460)，尺寸 260×106。
- ET：端侧任务业务确定处理目标；明确规则已能确定建议／动作；例：建议切换湿滑模式。位置 (50,1630)，尺寸 260×100。
- AI：云端业务补充判断；规则足够则直接明确处理目标；否则交主动推荐／模型工具；例：继续识别充电设备。位置 (370,1630)，尺寸 260×100。
- TARGET：本次处理目标明确吗？；条件满足、结果有效且未重复。位置 (90,1800)，尺寸 350×124。
- WAIT：不进入后续处理；条件未满足就等；识别不明不猜测；等下次有效更新。位置 (510,1800)，尺寸 130×124。
- MODE：查这项任务约定的交互方式；本次允许静默执行，还是需要先询问用户？。位置 (90,2000)，尺寸 350×66。
- SILENT：静默任务；当前表：儿童锁、后视镜加热；不出卡、不播语音；端云部署和执行规则仍须会签。位置 (40,2134)，尺寸 180×118。
- EASK：端侧询问（图二）；天气业务提供卡片内容；用户点击／本地按钮语音；选择回到天气业务。位置 (240,2134)，尺寸 180×118。
- CASK：云端询问（图三）；云端业务组织卡片；点击／语音走约定路线；本例由 Planner 承接。位置 (440,2134)，尺寸 180×118。
- CONSENT：这次得到有效确认吗？；两条询问链路分别校验当前选择。位置 (90,2330)，尺寸 350×124。
- CANCEL：未获有效确认；本次不操作车辆；拒绝／关闭／超时；不等于关闭整项任务。位置 (510,2330)，尺寸 130×124。
- PRE：端侧执行前复核通过吗？；任务仍有效、车况允许、没有重复。位置 (90,2532)，尺寸 350×124。
- ABORT：不执行新动作；过期／任务已关闭；车况不再允许；告知本次未执行。位置 (510,2532)，尺寸 130×124。
- CAR：赛力斯车控执行明确动作；端侧执行逻辑提交目标动作；收到请求不等于车辆已完成。位置 (90,2716)，尺寸 350×84。
- READ：执行业务读取真实车辆状态；达到目标：成功；明确未完成：失败；状态无法确认：结果暂不能确认。位置 (90,2856)，尺寸 350×84。
- RESULT：任务业务反馈结果并结束本次；有有效卡片才更新；按约定回传任务状态／记录；整项任务仍开启：等待下一次符合规则的场景；关闭任务不自动恢复已经改变的车辆功能。位置 (90,2996)，尺寸 350×106。

箭头：P → CAP（完整需求）；CAP → OK（能力与缺口）；OK → GAP（否）；OK → PUB（是）；PUB → TC（展示与接入资料）；TC → BIZ（用户操作）；BIZ → UI（结果）；BIZ → ON（可读取的任务状态）；ON → OFF（否）；PUB → ROUTE（任务规则与处理定义）；ON → ROUTE（是）；ROUTE → EDGE（端侧任务）；ROUTE → CLOUD（云端任务）；EDGE → ET（符合条件）；CLOUD → AI（值得继续处理）；ET → TARGET（明确建议）；AI → TARGET（明确结果）；TARGET → WAIT（否）；TARGET → MODE（是）；MODE → SILENT（静默）；MODE → EASK（本地询问）；MODE → CASK（云端询问）；EASK → CONSENT（本次选择）；CASK → CONSENT（本次选择）；CONSENT → CANCEL（否）；CONSENT → PRE（是）；SILENT → PRE（静默策略允许）；PRE → ABORT（否）；PRE → CAR（是）；CAR → READ（实际执行后）；READ → RESULT（真实结果）。
