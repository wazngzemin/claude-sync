# 时间的尽头 · THE LAST SECOND

一件以 Three.js 制作的交互装置。时间轴把宇宙的最后一秒拉长为 15 秒，从恒星的余烬到只剩一粒余光。

## 运行

`dist/` 是可直接托管的静态站，Three.js 和资源均随项目提供。在项目目录运行：

```sh
python3 -m http.server 8764 --bind 127.0.0.1 --directory dist
```

然后用浏览器打开 <http://127.0.0.1:8764/>。需要支持 WebGL 2 的浏览器。

## 操作

- 拖动画面环绕天体；滚轮或双指缩放；轻点核心发出回声。
- 拖动下方时间轴、点选章节，或播放最后一秒。
- 点击右上角开启声音或进入沉浸模式；Esc 返回。声音默认关闭。
- 键盘：画面聚焦后可用方向键环绕、加减键缩放、Enter 发出回声；空格播放或暂停，R 复位，M 切换声音，F 切换沉浸。

主要场景在 `dist/scene.js`，界面和声音交互在 `dist/main.js`。星云、尘盘、粒子、碎片和声音均由代码生成。Three.js 的 MIT 许可证位于 `dist/vendor/LICENSE`。
