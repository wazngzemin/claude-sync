# Carplay场景详细需求

支持按键唤醒 Siri/eSiri，及唤醒词唤醒 Siri/eSiri。CarPlay 语音和本地语音互斥。若当前为 CarPlay 语音或本地语音唤醒中，则另外一个语音唤醒不响应。

CarPlay Siri/eSiri 唤醒包括手机端唤醒和车机端唤醒。在 CarPlay 连接的场景下，两种唤醒方式均在车机端屏幕上显示 Siri。本地语音激活状态下，若通过手机端按键唤醒 Siri，则需退出本地语音。

本地 VR 的自定义唤醒词，建议避让 Siri 唤醒词，不能设置与 Siri 发音相近易造成混淆的唤醒词。



# 接口需求

生态域CarPlay\_语音策略 字节提供接口：

1\.豆包语音工作状态接口；\-\-\-场景：CarPlay激活时判断豆包语音工作状态，如豆包语音工作则siri不能被唤醒； 

2\.豆包语音打断接口；\-\-场景：carplay链接通过手机按钮激活siri，需强制打断豆包。 

上汽提供接口：（如飞书群附件）

1\.CarPlay语音工作状态接口。\-\-豆包语音激活前先判断CarPlay语音工作状态，如工作则不激活豆包语音。
