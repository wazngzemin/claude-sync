# 四、 功能详细说明

## 产品流程图



## 4\.1 截断召回判断

此部分需求为语音VAD的第一阶段需要实现的基础功能，能覆盖绝大部分语音vad场景。通过时间和语义拒识的组合，来识别是否要召回当前截断的query。



### 4\.1\.1 第一段判断： 短时截断

用户说话时，持续asr识别文字，当用户出现**停顿100ms时****，定义为短时**，则截断文本，作为第一段query判断是否要召回。

此时，

**通过大模型判断语句是否要召回**

- 若不拒识，则视为query完整且可以召回，则继续配合意图走后续插件链路。

- 若拒识，则视为query暂不要召回，继续走4\.1\.2流程。

**和拒识判断并行意图识别，以达到最优性能**

- 若拒识模型出结果要拒，则结束并行的意图执行。



例子，

*“介绍一下”……停顿100ms →进入拒识（并行意图）→拒识（停止意图）*

*“介绍一下蓝精灵”……停顿100ms →**进入拒识（并行意图）**→召回（配合意图继续执行插件）*



注意asr的过程仍然是一起识别的，不要截断分开做asr。



### 4\.1\.2第二段判断： 中时截断

当中时截断后，用户在限制稍长的时间（**定义为中时，500ms）**内又进一步说话，则视为连续同一句话，并且再次**出现短时停顿100ms后**，和前面在短时内所有的话拼接一起判断，是否要召回。

此时，

**通过拒识判断语句是否要召回**

- 若不拒识，则视为query完整且可以召回，则继续配合意图走后续插件链路。

- 若拒识，则视为query暂不要召回，即便上一段query召回也停止，并停止4\.1\.1中的其他任何模型插件执行。

**和拒识判断并行意图识别，以达到最优性能**

- 若拒识模型出结果要拒，则结束并行的意图执行。



例子，

*“介绍一下”……停顿100ms →进入拒识（并行意图）→拒识（停止意图）*

*→500ms内继续说“泰勒斯威夫特”**→**合并成“介绍一下泰勒斯威夫特”*

*→进入拒识（并行意图）→召回（执行插件）*

→500ms内继续说“的猫”→合并成“介绍一下泰勒斯威夫特的猫”

*→进入拒识（并行意图）→召回（执行插件）*



*“介绍一下蓝精灵”……停顿100ms →进入拒识（并行意图）→召回（配合意图继续执行插件）*

*→500ms内继续说“这个语文作文你写了没”→合并成“介绍一下蓝精灵这个语文作文你写了没”*

*→进入拒识（并行意图）→拒识 → 停止执行上一段“介绍一下蓝精灵”处理*



## 4\.2 打断交互

用户在对话中AI播报tts的时候，如果说了query，并且在第一次短时截断的时候，未被拒识，则端上打断tts播报。
