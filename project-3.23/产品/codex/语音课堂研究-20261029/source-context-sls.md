# 产品概述

Context广义上指模型推理的上下文，作用是让模型“看见”当前正在发生什么。

在AI汽车项目上，context包含端状态、记忆、世界信息、情景描述、事件等信息，context模块，承担的是将各类感知信息更好地组织好，给到DT使用的职责。

#### 信号屏蔽

1. 屏蔽特定信号：

    ❌ 座椅位置状态

#### 输出格式转换

1. 输出格式yaml，参考以下模板。

```YAML
信号名称（无主key）:
  参数名: 参数值
信号名称(带主key):
  _参数顺序_: [参数名1, 参数名2(单位说明), 参数名3(单位说明)]
  主key参数名: [参数1值, 参数2值, 参数3值]
```

注：当主key外只有一个参数时，直接以“【主key】【参数名】：【参数值】”输出，不使用列表。如：

```YAML
车内温度：xx
车外温度：xx
```

2. 后处理输出时，工程上合并部分信号，优化模型对同类信号的注意力：

a\. 空调四合一：车内空调状态、空调风向模式、空调循环模式、空调制冷开关状态

b\. 导航二合一：导航状态、目的地位置、途经点位置、沿途服务区位置

c\. 音频二合一：当前播放音频、播放模式和状态

d\. 视频二合一：当前播放视频、播放模式和状态

## 事件流

时序事件流扮演的是“串联”角色，即把一帧一帧的定格画面，连接成了一段电影。让ai从一个个孤立的切片中，看到了情境的全貌，并启发ai发现和理解用户对话和行为之间的“**内在因果**”。

### 事件流独立变量

1. Context提供事件流窗口变量，将**10分钟内**（暂定）**最多30条**（暂定）的事件流倒序注入DT。

```Markdown
# 事件流（倒序）
1. 9分28秒前，用户打开了系统设置页面。
2. 8分00秒前，用户通过按键设置主驾空调为23度。
3. 6分17秒前，小明语音搜索并播放了周杰伦的简单爱。
.
.
.
97. 2秒前，小红在副驾睡着了。
```

2. 窗口滚动机制：先进先出。即在窗口内，新事件默认挤出旧事件。

### 拼入对话历史

1. 重要事件（参考下文表格）进对话历史上下文，和query按时序排列。

2. 事件截取窗口：当前轮次query和最旧的query时间段内的事件。

```Plain Text
"event":"6分17秒前，小明语音搜索并播放了周杰伦的简单爱。"
"query":"帮我打开车窗"
"event":"8分00秒前，用户通过按键设置主驾空调为23度。"
```
