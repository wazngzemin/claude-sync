# 触发器配置平台：页面原型交付

本交付包含六页同源截图、截图讲解稿和可点击 HTML。页面结构参考技术方案 3.8：场景列表、场景配置、三个任务的 Workflow 示例、运行详情。三个判断示例属于同一配置画布，不新增三个实际后台菜单。

使用：用浏览器打开 HTML。从 P1 查找场景，查看生效范围；从 P2 配基础信息和建议 Query；从 P3—P5 查看判断依赖。既有判断只读，先复制再编辑。在 P6 切换 PASS / REJECT / UNKNOWN，看节点原因及分层结果。

已操作验证：渠道筛选无匹配结果、重置、范围弹窗、只读复制、循环连线错误、独立本地副本生成、缺失能力阻断、未知运行结果。HTML 无外部脚本依赖，不调用真实平台和车辆。保存仅作用于页面内存；刷新重置。运行记录为儿童锁演示，不冒充其他任务实测数据。

配置口径：带按钮 Action 只填写固定建议 Query；确认／取消自动提供。卡片正文与 TTS 下游生成。图中只放条件／推理；工具调用、卡片和车控不放进判断图。
