# 一、场景推荐引导语

上电时触发，以引导气泡（文字 + emoji，emoji 为非必出项）主动向用户推荐可直接说出的常用指令与场景玩法，**每次上电变化**，共 7 条：

- **常用指令（3 条）**：结合**用户记忆与历史行为**，从**导航、车控、多媒体、系统应用设置**等高频域中提炼用户当前场景下的高频指令。例如：开启全车极速降温。
- **场景推荐（4 条）**：基于**当前场景 + 车内乘客状态**，动态推荐场景化玩法。例如：周末密室逃脱出游。

缓存策略另行定义。

| 字段名 | ~~字段名~~含义 | 类型 | 必填 | 说明 |
|-|-|-|-|-|
| guiding_id | 引导语ID | 字符串 | 是 | 唯一标识 |
| guiding_type | 引导语类型 | 枚举 | 是 | 常用指令 / 场景推荐 |
| guiding_content | 文案 | 字符串 | 是 | 气泡展示文字 |
| emoji | emoji | 字符串 | 否 | 非必出项，按需展示 |
| query | 触发Query | 字符串 | 是 | 点击气泡触发的语音 Query |

整体策略，话术上让用户感知AI代表着整个系统，体现鲜活与温度，建立HMI和用户建立连接的仪式感

# 二、场景推荐任务

基于用户场景生成的可执行任务，**触发时机与引导语一致（上电触发），场景来源逻辑与引导语相同**（用户记忆 / 历史 + 当前场景 + 车内乘客状态）。**导航、音乐播控、车控**三类做特殊化处理：输出对应的执行文本 + 直达按钮（导航按钮 / 播放按钮 / 执行按键），支持一键执行；其他类型统一使用"执行按键"（样式同车控）。缓存策略另行定义。

| 枚举名 | 场景类型 | 结果展示 | 操作按钮 |
|-|-|-|-|
| Navigate | 出行导航 | 具体导航结果 | 导航按钮（含目的地名称） |
| Music | 音乐 | 推荐音乐 | 播放按钮 |
| VehicleControl | 车控 | 对应车控 | 执行按键 |
| Other | 其他类型 | 对应任务 | 执行按键（同车控） |

| 字段名 | 含义 | 类型 | 必填 | 说明 |
|-|-|-|-|-|
| scene_id | 场景ID | 字符串 | 是 | 唯一标识 |
| scene_type | 场景类型 | 枚举 | 是 | 类型枚举，对应上表 |
| title | 场景标题 | 字符串 | 是 | 标题 |
| desc | 场景描述 | 字符串 | 否 | 介绍信息 |
| icon | 场景图标 | 字符串 | 是 | 图片url地址 |
| query | 执行目标 | 字符串 | 是 | 点击按钮触发的链接 / Query / 指令 |
| track | 运动轨迹 | 字符串 | 是 | 枚举类型，建议端侧设置默认值，应对返回了不支持的枚举类型（枚举可能随业务发展而增加，量产后的老版本客户端拿到不支持的枚举时，需按默认效果展示） |
| element | 元素 | 字符串 | 是 | 枚举类型，建议端侧设置默认值，应对返回了不支持的枚举类型（枚举可能随业务发展而增加，量产后的老版本客户端拿到不支持的枚举时，需按默认效果展示） |

# 三、技能 Skill

在 Launcher 应用中心展示的技能清单，按分类组织，含名称、ID、固定图标与云端触发 Query；**当前固定本地缓存，后期支持云端更新**。

排序逻辑（自上而下，参考UI）：

1. **最近一次使用**：置顶。
2. **偏好推荐位**：基于用户偏好推荐，共 **3 个**推荐位，紧随最近使用之后。
3. **其余技能**：**未使用**的靠前，**已使用**的靠后；系统需为每个技能标记"**已使用 / 未使用**"标识。

| 字段名 | 含义 | 类型 | 必填 | 说明 |
|-|-|-|-|-|
| skill_id | Skill ID | 字符串 | 是 | 唯一标识 |
| skill_name | Skill 名称 | 字符串 | 是 | 应用中心展示名称 |
| desc | Skill描述 | 字符串 | 否 | 描述信息 |
| category | 分类 | 字符串 | 是 | 技能所属分类 |
| icon | 图标URL | 字符串 | 是 | 固定对应图标 |
| query | 云端Query | 字符串 | 是 | 触发到云端的 Query |
| use_status | 使用状态 | 布尔值 | 是 | 是否已使用（用于排序：未使用靠前，已使用靠后） |
| last_use_time | 最近使用时间 | 时间戳 | 否 | 用于"最近一次使用"置顶排序 |
| prefer_position | 偏好推荐位 | 整数 | 否 | 偏好推荐位序号（1-3），未命中为空 |
