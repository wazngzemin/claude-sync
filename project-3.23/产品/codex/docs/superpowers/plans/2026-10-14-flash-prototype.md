# 闪念交互原型改造 Implementation Plan

> **For agentic workers:** 本环境没有 subagent-driven-development / executing-plans skill；使用协作工具实现，主代理逐项验收。

**Goal:** 在 v04 上增量增加闪念配置与交互演示，不改 PRD 和真实平台。

**Architecture:** 保留 P1–P6 及原有场景。新增 P7 闪念配置、P8 闪念试跑，从场景列表及新建入口可达。Action 与条件分开；试跑由用户手工选择模拟判定，绝不假装真实模型调用。

**Tech Stack:** 单文件 HTML / CSS / 原生 JavaScript，离线可用，localStorage 仅保存演示草稿。

**Spec:** Meeting-Summary-2026-10-14-豆包闪念触发器需求.md（位于用户的触发器包含条件目录）及已批准的本轮增量说明。

## Global Constraints

- 新文件：HTML/01-进行中/触发器配置平台-交互原型-v05.html；不覆盖 v04。
- 已验证交付后复制到 HTML/02-已交付/。
- 一期为固定文案；条件判断先复用已有模型。动态文案、PHUD 接口不能假装可用。
- 普通通知卡，正文无标题／按钮／TTS；Frontier 为已选方向而非原型中的真实连接。
- 所有例句、策略值、模型判定和展示结果标记演示；当前视觉入口未接通、排队版本待核实。
