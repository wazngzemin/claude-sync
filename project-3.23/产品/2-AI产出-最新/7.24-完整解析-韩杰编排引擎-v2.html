三、每种积木在 Excel 里怎么填？（逐字段，带真实值）

▍触发事件：以 tri_gear（档位切换）为例 — 触发事件 sheet 第 2 行

字段tri_gear 的真实值什么意思
唯一标识tri_gear积木 ID。画流程图时写这个 ID，研发就知道要监听档位变化。
分类车况车况/导航/用户操作/环境感知/软件状态。方便在大表里按分类找积木。
事件名称档位切换中文名，给人看的。
参数名档位这个事件发生时附带什么信息。"档位切换"事件附带的信息就是"新档位是什么"。
参数值范围P / R / N / D参数能取的值。研发就按这个枚举去接信号。
切换类型切入 / 切出关键字段。"切入 P" = 变成 P 档时触发。"切出 P" = 从 P 档变走时触发。你填"切入"。
事件描述模板档位由【触发前】切换为【触发后】触发后自动生成一句描述。给事件日志用的。
关联状态查询VehDriveState这个事件对应的端状态变量在"状态查询"sheet 的哪一行。查信号来源用。

▍条件：以 con_gear（档位判断）为例 — 条件 sheet 第 2 行

字段con_gear 的真实值什么意思
唯一标识con_gear积木 ID。
条件名称档位中文名。
关联状态查询VehDriveState从哪个端状态读值。和 tri_gear 关联同一个状态——它们是一对：tri_gear 监听变化，con_gear 判断当前值。
参数名类型判断方式。con_gear 的类型字段只有"是"和"非"两个选项。
参数值范围是 / 非"是 P" = 档位等于 P。"非 P" = 档位不等于 P。这就是韩杰说的"非"（NOT）。注意和 con_speed 不同——con_speed 是数值比较（大于/小于/等于），con_gear 是状态匹配（是/非）。
支持多选否能否一次判断多个值。con_gear 不支持多选——你不能一次判断"档位是 P 或 N"。但 con_occupancy（座位占用）支持多选——能一次判断"副驾或二排有人"。

▍动作：以"调 Advisor"为例 — 动作 sheet 第 3 行

字段调 Advisor 的真实值什么意思
唯一标识Advisor积木 ID。
动作名称智能顾问中文名。
动作类型调 Advisor属于哪类动作。调 Advisor / 生成事件日志 / 控车 / 弹主动服务卡 / 调 Director。
输入参数Advisor 类型：舒适/出行/内容/情感执行这个动作时要传什么参数。调 Advisor 需要指定类型——低电量提醒调"舒适"，兜风推荐调"出行"。
执行位置云端在端侧还是云端执行。Advisor 是大模型推理，放云端。
谁来填这些字段 = 谁在定义这个积木的能力边界。
· "支持多选"填是还是否 → 决定了条件能一次判断多个值还是只能单个 → 直接影响场景怎么写
· "切换类型"有没有切入/切出 → 决定了事件能区分方向还是只能"变了就触发"
· "参数值范围"写哪些枚举值 → 决定了这个积木覆盖多少场景

韩杰现在填了大部分行。你 7.23 核出的 3 个缺口——你如果把新增行的字段填好发给他，就是你定义的。
