# 自学习四种方式与内核连续性整合

[完整整合精讲与会上发言示例](../../产品/codex/Meeting-Summary-2026-11-04-自学习与内核整合精讲-v01.md)。

9 月会议重点是把正确做法交给模型，11 月会议扩展到持续理解用户与当前场面。应串成：经历产生线索 → 判断依据与原因 → 提炼有条件的候选内容 → 确认范围并保存 → 下一次找到并使用 → 检查真实结果。

## 三个不同问题

- 四种方式回答经验从哪里来，彼此有交叉，不是四个已定模块。
- 五本账回答经历改变哪类内容，未证明已建成对应物理存储。
- 实时与后台回答什么时候更新；即时情境、情绪和长期关系、人格需要不同证据与节奏。

Planner 接到背景后仍需按当前用户目标决策、调度、读取反馈；背景丰富不自动证明目标完成。

## 新证据带来的修正

1. 11 月 4 日 00:08:32、00:18:51、00:47:59、01:08:45–01:10:43 为主动探索提供内部出处。
2. 夜间猜想应保持待确认属性，不直接覆盖明确偏好或亲属身份。
3. 当场补救与长期学习需要分开验。
4. 摘要对卖车归属的说法与 00:34:59 逐字稿有差异，不能定案。
5. 01:01:14 明确讨论快频率上下文准备不在内核，不能合并成单一已定实现。

## 可复用的会议推进方法

先问用户看见什么变化；再拿一个完整例子走输入、判断、执行、反馈；用反例查依据与适用条件；最后收口第一版输入输出和可观察结果。

例如：餐厅工具无结果是否属于模型错误？未确认的长辈是否能按岳母服务？后台准备好了内容是否应该立刻开口？每个追问都应对应一个会影响用户结果的决定。
