**本文为火山引擎智能座舱面向弋途（Extour）服务端提供的 HTTP 接口说明**，所有请求都需要验证签名，并需要访问 HTTPS 地址。本文档仅包含弋途专用接口，不包含车机客户端和公版通用接口。
# 请求地址
**服务端调用**：api\-vehicle\-cloud\.volcengine\.com（无 DCDN 加速，适合固定机房发起的调用，网络开支更少）
**环境**
**说明**
DEMO 测试环境
务必在请求 Header 中额外添加下列 header 信息：
- X\-Use\-PPE : 1
- X\-Tt\-Env: ppe\_XXX（ppe环境用于联调，具体值在对应项目联调时找火山研发同学提供）
# 请求频次限制
- **渠道默认限制 600 QPM**，即每分钟最多 600 次请求，超过的请求会被拒绝
- **单设备默认限制 60 QPM**，即每分钟最多 60 次请求，超过的请求会被拒绝
如有提升 QPM 的需求，请和行解、项目、产品沟通。
# 接口超时配置
所有接口最大响应时间为**3 分钟**，长连接最大空闲时间为 **3 分钟**，请务必复用长连接，避免重复 TLS 握手带来的额外时间开销（100\+ 毫秒）。

## Goal 生命周期回调 @姜涵
- **Method**：`POST`
- **Path**：`/aidv/v1/goal/lifecycle\_callback`
- **Content\-Type**：`application/json`
- **超时**：2 秒
弋途异步创建任务后，通过此接口回调 AIDV 通知任务创建结果或触发事件。接口基于 `idempotent\_key` 做幂等处理（有效期 30 天）。
#### 请求 Body 参数
**参数**
