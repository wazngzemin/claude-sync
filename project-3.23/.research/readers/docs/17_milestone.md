# AI Car产品里程碑计划

<callout emoji="💡">
主要表示产品对重点新增模块计划期望，旨在定义大里程碑目标，其他基础功能优化详见FL。  
  
**阶段一：**8-9月，针对打造智能上限的AI能力，搭建试验车并跑通，进入打磨轨道；
**阶段二：**10-11月，完成繁复的接入类工作，如语音、生态等，并对阶段一智能化能力打磨。  
期望在12月前全链路和模型框架搭建完成，进入for量产的下一步打磨优化阶段。
