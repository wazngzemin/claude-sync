- 车辆碰撞: 有其他车辆与本车发生碰撞，包括正面撞击或侧面刮擦，其他车辆包括两轮车、三轮车、四轮车、小推车、超市购物车等有轮子的车辆。

- 轮胎操作: 人员用手或者工具接触轮胎，比如用手碰轮胎、用手拧开气门芯放气、在车轮前后摆放不倒钉等。

**任务**
图片中存在一个或多个红色矩形框，每个框标识一个人。请对每个框中的人依次判断以下三种特征：
1. 是否携带显著且体积较大件物品、小物品或者无物品
2. 是否怀抱婴儿
3. 是否是行动不便的人

判断时请按顺序逐项确认：先判断物品，再判断婴儿，最后判断行动不便。

**说明**
### 是否携带显著且体积较大件物品、小物品或者无物品
1. 大件物品包括但不限于如下类型：
   行李箱（例如：拉杆箱、旅行箱）
   购物车（例如：超市购物车）
   手提袋或手提包（挎在手臂上或者手上拎着的各种购物袋和提包如果遮挡了三分之一身体或是双手托举则属于该场景）
   箱子（例如：纸箱、搬家箱、箱子类的包裹）
   袋子（体积较大的编织袋、旅行袋、超市大号袋子类的包裹等）
   背包（体积较大、背负在肩部的包、双肩包或单肩包）
   其他大件物品（例如：婴儿车、大型乐器、滑雪板、高尔夫球包等，任何明显占用空间或需要较大力气搬运且不属于上面类别的物品）
2. 小物品定义为体积较小或者随身携带的物品，包括如下类物品：
   手机、水瓶、雨伞、平板电脑、小尺寸手提包/挎包、钥匙、零食、文件等体积小、重量轻、便于单手持握的日常随身物品。
3. 无物品：未携带任何上述物品。

注意事项：
1. 如果当前标识人同时携带多件大件物品，请输出最明显的物品类别。
2. 如果未观察到任何符合标准的大件物品，但携带体积较小或随身的物品，请输出："小物品"。
3. 如果未观察到任何上述物品，请输出："无物品"。
4. 若因图像模糊、遮挡等原因无法明确判断，请输出："无物品"。

### 是否怀抱婴儿
怀抱婴儿：可以直接看到当前标识人怀里抱着小孩子，抱着像襁褓式的物品，或者抱着提着婴儿篮等。

注意事项：
1. 指可明确看到当前标识人怀中抱着婴儿或婴儿载体。
2. 明确可见：图像中需能清晰辨认出当前标识人怀抱的是婴儿、裹有婴儿的襁褓式物品，或手提的婴儿篮。
3. 排除宠物：怀抱的若为可辨识的宠物（如猫、狗），则不属于此场景。
4. 若被襁褓等物品完全遮挡，无法看清内部，可视为婴儿，请输出："是"。
5. 若因图像模糊、拍摄角度等原因无法明确判断，请输出："否"。

### 是否是行动不便的人
行动不便：可以看到当前标识人坐轮椅，拄拐杖，脚被纱布包扎等有不便于行动的特征。

注意事项：
1. 拄拐：指可明确看到当前标识人正使用拐杖辅助行走。
2. 坐轮椅：指可明确看到当前标识人正坐在轮椅上。
3. 脚腿被纱布包扎：指可明确看到当前标识人的脚部或腿部有明显的纱布或绷带包扎。
4. 若因图像模糊、遮挡等原因无法明确判断，请输出："否"。

**输出格式**
每人输出一行，格式为"是否有大件物品-是否怀抱婴儿-是否行动不便"。
- 图中只有一个红色矩形框（无数字标注）时，只输出一行结果。
- 图中有多个红色矩形框（框上标有数字）时，按框上的数字顺序依次输出，第一行对应1号框，第二行对应2号框，以此类推。
只输出结果，不要有任何额外说明文字。

各字段可选值：
