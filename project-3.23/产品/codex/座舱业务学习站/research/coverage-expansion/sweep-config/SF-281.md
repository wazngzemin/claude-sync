# 家悦07路试注意事项

## 一、活动性质与测试范围

- 本活动是种子用户内部测试，不是正式商用体验。

- 产品仍处于测试阶段，可能出现识别错误、任务执行失败、系统崩溃、版本变更或临时暂停。

- 智能驾驶、代客泊车、未开放的交易类功能、系统内置第三方应用等不在本次测试范围内。

- 豆包给出的回复仅供参考，需要测试者自行决定是否采纳。

- 测试反馈不代表产品一定采纳，也不构成最终产品能力承诺。

## 二、行车安全与风险提示

- 驾驶安全优先，驾驶员不得在行驶中操作手机、填写问卷、拍摄视频或长时间观察车机界面。

- 涉及视频采集的任务，应由乘员完成或在车辆安全停放后进行。

- 不得为了完成测试任务实施危险驾驶、测试智能驾驶边界或违反道路交通法规。

- 遇到车控异常、语音误执行、系统无法唤醒或其他可能影响安全的问题，应立即停止相关测试并联系工作人员。

- 其他行车安全相关依照《家越07路试车辆使用承诺书》执行

## 三、车辆交付、使用与责任

- 路试交付物包括：车辆、钥匙、临牌（如因临牌产生的违章罚款需自行处理）

- 登记情况：车辆现状（含车内外照片、视频）、车牌号、VIN号、身份证复印件、驾驶证复印件、归还时间。

- 取车流程：测试者提前与我方联系取车时间\-\-测试者前往漕溪北路400号取车（上海）\-测试者提供身份证复印件、驾驶证复印件\-签署相关协议\-工作人员讲解使用须知\-工作人员登记车辆现状（含车内外照片、视频）留档并发予测试者\-交接交付物

- 还车流程：测试者提前与我方联系还车时间\-\-测试者前往漕溪北路400号还车\-工作人员审核车辆状态\-沟通赔付（如有）\-工作人员登记车辆现状（含车内外照片、视频）\-交接交付物

- 保险范围（待确认）

- 不允许使用车辆进行商业行为（包括不限于载客、运货等），可以用于日常生活场景，如通勤、购物、短途自驾游。

- 禁止擅自拆机、刷机、维修、安装未经批准的软件或改变车辆配置。

- 车辆归还时需要清除个人账号、历史记录及其他个人数据。

车辆和豆包汽车能力可能包含未公开信息，所有参与者（包括车上的其他乘客）都承担明确的保密义务。

    1. 与研发、生产、产品、服务、客户及市场有关的任何及全部业务信息、财务信息、技术数据、生产资料、会议材料及文件，包括但不限于原型机、零部件、硬件配置信息、软件、程序、发明、技术、设计、图纸、专有技术、工程资料、工作流程、方法、客户名单、员工信息、合同、价格、成本、研究报告、预测与估算、报表、商业计划、商业秘密、商业模式、公司决议等；

    2. 尚未公开的实物，包括原型产品、零部件、包装及配件；产品信息，包括原型机的功能、外观设计、技术参数及操作系统版本；使用过程中收集的体验数据，包括用户反馈、使用行为及性能数据；配套的书面或电子材料，包括使用说明、技术文档及体验指南；以及与产品有关的战略信息，包括商业计划、发布时间安排及市场定位；

    3. 签署人在参与本项目过程中接触到的公司尚未披露的任何产品信息、技术方案、商业计划、测试流程、测试结果等；

    4. 公司因本项目需要向签署人提供的，与软硬件产品有关的全部材料、数据信息，以及公司已采取保护措施进行管理的其他任何材料或信息；

    5. 以任何形式形成、且全部或部分源自保密信息的任何记录、摘要、报告、分析或其他材料。

2. 在本项目实施期间及结束后，签署人**不得且不会**实施下列行为：

    1. 以任何形式记录或留存与本项目有关的任何信息，包括但不限于拍照、录像、录音、记笔记、绘图等；

    2. 向除为本项目目的与签署人进行接洽的人员或其他本项目参与者之外的任何人员，打听、讨论或传播与本项目有关的保密信息；

    3. 以任何方式或形式，包括但不限于通过社交媒体、公开演讲、文章、采访等，向任何第三方（包括家人、朋友、同事等）公开、讨论或披露其参与本项目的事实，或披露与本项目有关的任何信息，例如测试内容、测试体验或测试结果；

    4. 基于本项目实施过程中获得的信息，对公司产品作出任何形式的推测、评论或发表相关言论；

    5. 以其他任何方式使任何第三方知悉保密信息，和/或为签署人本人或任何第三方的利益使用保密信息；

    6. 未经授权留存、复制、修改、反向工程、拆解保密信息，或以其他任何方式试图获取保密信息所包含的核心技术内容；

    7. 将测试过程中接触到的保密信息用于任何个人或商业目的；

    8. 出借原型机、公开展示其外观、用于测试以外的目的，或进行流转，包括但不限于转售；

    9. 移除或遮盖设备上的保密标识或标签；

3. 签署人承诺，在本项目期间及结束后，主动采取一切合理措施保护公司的保密信息，包括但不限于：

    1. 一旦发现可能导致保密信息泄露的行为或风险，例如他人询问测试内容、设备出现异常等，立即向公司报告；

    2. 测试结束后，积极配合公司清理测试信息，确保不留存、不泄露任何保密信息；

    3. 在本项目期间及结束后持续履行保密义务，直至本承诺书约定的保密期限届满，或相关信息已通过合法途径公开；

    4. 持续关注公司发布的与本项目有关的保密要求，并及时调整自身行为，以遵守最新规定；

    5. 如知悉任何第三方已获得公司的任何保密信息，应及时书面通知公司，并提供其所知悉的全部相关情况。

- 测试期间可能远程安装、升级、回滚或暂停某些功能。

- 远程升级可能造成短时不可用、数据变化或需要车辆保持特定状态。

- 工作人员可能基于 User ID、时间和日志远程定位问题，但不会在未告知的情况下任意操作车辆。

- 使用微信、支付宝等第三方应用时，应遵守第三方规则；不建议在测试车内保存支付密码或高度敏感信息。
