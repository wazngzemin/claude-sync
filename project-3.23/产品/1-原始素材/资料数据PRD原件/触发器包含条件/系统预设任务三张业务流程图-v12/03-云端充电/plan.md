# 03｜云端充电口盖业务流程

类型：自上而下业务流程图；28 个节点；画布 680 × 3840。

- TC：用户开启充电口预设任务；任务中心转发操作；充电任务接入方保存真实结果；真实任务状态提供给云端触发器；开关不等于授权。位置 (90,170)，尺寸 350×84。
- UP：车端上报已接入的车辆信息；例：档位由D变P、电量18%、充电口盖关闭；同时提供任务有效状态、AI主动服务开关状态；P挡连续上报多次，仍然只算同一次停车。位置 (90,310)，尺寸 350×106。
- HARD：本次充电前置条件满足吗？；满足只代表值得检查。位置 (90,646)，尺寸 350×124。
- WAIT：不满足：继续等；不启动设备检查；不出开盖卡；等待下次适用事件。位置 (510,646)，尺寸 130×124。
- COND：云端触发器检查充电规则；任务有效＋AI主动服务开＋非P变P；电量≤20%＋口盖关闭＋本次停车未重复；此时还不知道旁边有没有充电设备。位置 (90,472)，尺寸 350×106。
- QUERY：触发器发起一次主动推荐请求；交给主动推荐：本次停车场景＋设备检查目标；Query示例：看看有无充电桩，有的话打开充电口；这是系统检查请求，不是用户本次开盖授权。位置 (90,814)，尺寸 350×106。
- DT：主动推荐调用 DT 协作判断；DT接收场景问题，按现有能力请求视觉问答；端侧视觉问答基于当前画面判断有无设备。位置 (90,998)，尺寸 350×84。
- OBS：端侧视觉能力返回观察结果；区分：有设备、无设备、不能判断、调用失败；结果必须对应本次停车，不能拿旧观察充数。位置 (90,1138)，尺寸 350×84。
- FETCH：端侧按现有链路上行获取 DT 结果；保留原链路的“端侧取到推理结果”这一步；取到结果后，不能绕过新增的二次确认直接执行。位置 (90,1278)，尺寸 350×84。
- FOUND：当前明确发现设备了吗？；推理结果有效，仍是这次停车。位置 (90,1418)，尺寸 350×124。
- NOCARD：无／未知／失败；过时也不能继续；不出开盖确认卡；不打开充电口。位置 (510,1418)，尺寸 130×124。
- HANDOFF：待确认：谁把结果转成开盖建议？；端侧结果接入方 → 充电建议承接方 → Planner；需会签接收方、当前建议关联、确认前拦截执行；此箭头表达必须补齐的交接，不表示已经接通。位置 (90,1598)，尺寸 350×106。
- PLANNER：沿静态 Advisor 询问链路交 Planner；Advisor是主动推荐；Planner承接当前建议和对话；带上本次停车、要打开的口盖、建议有效范围；本任务最终选用此卡片路线，仍须接入会签。位置 (90,1782)，尺寸 350×106。
- CARD：Planner给车机即时卡发送询问内容；问“要打开充电口吗？”；提供按钮与播报内容；车机卡片／VUI负责受理、排队和真正显示。位置 (90,1948)，尺寸 350×84。
- SHOW：本次卡片已展示且有效吗？；排队未显示，不等于用户已看见。位置 (90,2088)，尺寸 350×124。
- QUEUE：暂未展示；排队且有效则等待；过期／失败则终止；没有确认不开盖。位置 (510,2088)，尺寸 130×124。
- VOICE：用户语音回答；当前语音＋当前卡片上下文；一起交给 Planner；理解这次说的是哪个建议。位置 (50,2270)，尺寸 260×106。
- CLICK：用户点击确认或取消；静态 Advisor 卡：模拟 Query；带上当前按钮和建议的对应关系；发给 Planner；不直接车控。位置 (370,2270)，尺寸 260×106。
- INTENT：Planner处理本次回应；明确同意才进入开盖；明确拒绝则结束本次；关闭或超时没有授权；其他诉求转正常对话；例：“不要，帮我找充电站”不算同意开盖。位置 (90,2452)，尺寸 350×106。
- CONSENT：明确同意这一次开盖吗？；回应未过期，当前建议未被消费。位置 (90,2614)，尺寸 350×124。
- CANCEL：不执行本次开盖；拒绝／关闭／超时；旧卡／不明确回应；新诉求另走正常对话。位置 (510,2614)，尺寸 130×124。
- REQUEST：Planner请求端侧执行本次开盖；带上本次任务、停车与建议的关联信息；不能只发一个脱离场景的“确认”。位置 (90,2794)，尺寸 350×84。
- PRE：端侧最新状态允许开盖吗？；任务有效、仍是本次停车、仍在P挡。位置 (90,2962)，尺寸 350×124。
- ABORT：不发新开盖请求；车况变化／已失效；已经处理／已经打开；回传原因或当前状态。位置 (510,2962)，尺寸 130×124。
- GUARD：端侧执行逻辑复核完整适用范围；口盖仍关闭、结果和确认未过期、没有重复；遵守车辆动作限制；未知状态不当作允许；启动阈值哪些也要用于复核，由业务与车控会签。位置 (90,3142)，尺寸 350×102。
- EXEC：赛力斯车控打开充电口盖；端侧提交明确开盖动作；车控处理请求；请求返回成功，不等于口盖实际已打开。位置 (90,3300)，尺寸 350×84。
- REAL：端侧读取充电口盖真实状态；已打开：成功；明确无法打开：失败；真实状态无法确认：暂不能确认成功。位置 (90,3440)，尺寸 350×84。
- RESULT：回传本次结果，更新卡片与云端上下文；端侧把真实结果给本次充电业务／Planner；有有效卡片再更新；按约定保存本次处理记录；本次结束，长期任务继续等下一次合适停车。位置 (90,3580)，尺寸 350×106。

箭头：TC → UP（任务状态已可读取）；UP → COND（本次停车与当前状态）；COND → HARD（逐项检查）；HARD → WAIT（否）；HARD → QUERY（是，只启动检查）；QUERY → DT（检查请求）；DT → OBS（观察问题）；OBS → FETCH（DT协作得到判断）；FETCH → FOUND（本次推理结果）；FOUND → NOCARD（否）；FOUND → HANDOFF（是，形成待确认建议）；SHOW → INTENT（关闭／超时）；HANDOFF → PLANNER（待接入会签）；PLANNER → CARD（当前建议与询问）；CARD → SHOW（展示结果）；SHOW → QUEUE（否）；SHOW → VOICE（是，语音回答）；SHOW → CLICK（是，手动点击）；QUEUE → SHOW（可显示再检查）；VOICE → INTENT（语音与上下文）；CLICK → INTENT（模拟的 Query）；INTENT → CONSENT（判断用户意图）；CONSENT → CANCEL（否）；CONSENT → REQUEST（是）；REQUEST → PRE（执行请求）；PRE → ABORT（否）；PRE → GUARD（是，继续核对）；GUARD → EXEC（全部通过）；GUARD → ABORT（任一不通过）；EXEC → REAL（车辆处理后）；REAL → RESULT（真实结果）。
