白领大逃杀，比预期的来得更迟

纯银这篇说：AI 推动的白领大逃杀不会很快来，最低还要 5 到 10 年。理由不在 AI 强不强，在人跟不跟得上：普通人靠 SOP 无限复用省脑力，Agent 时代没有 SOP，每个任务都要现编 harness，这种持续支付脑力的活，大多数白领干不了。这篇几乎是照着你的处境写的，你恰好就是那个愿意支付脑力的提效狂魔，这一版把文章每一个论点都落到你身上。

01

一句话讲透这篇

纯银在 2025 年预言过「白领大逃杀」（AI 大规模替代白领工作）。2026 年他亲自用上 Agent 之后，反而把预言往后推了：5 到 10 年内，大逃杀不会全面到来。

他的理由一条线讲完：AI 确实强，但用 AI 干活的人跟不上。普通人的工作方式是把技能沉淀成 SOP、无限重复、靠微调省脑力；Agent 时代没有 SOP，每个任务都要单独设计一套运行规则（他叫 harness），环境一变规则就要跟着改，这是持续烧脑的活。大多数白领烧不起这个脑，所以市场上永远凑不出足够的「Agent 工程师」，公司想切也切不动，于是大逃杀无限推迟。

这篇和上次那篇《需求爆兵》是姊妹篇：爆兵讲「公司没变快，因为组织问题」，这篇讲「大逃杀不来，因为人的问题」。两篇合起来一句话：卡住 AI 落地的，从来不是 AI，是人。

这篇对你几乎是量身定做的，因为你就是文章说的那种人：愿意为每个任务打磨 harness 的提效狂魔。下面每节都先讲文章，再把你放进去。

02

第一个论点：SOP 失灵，大多数人靠省脑力活着

原文说啥

「大多数人的工作方式：花时间学习一些技术和方法，沉淀成自己的 SOP，无限次地重复 SOP。在无限次重复的过程之中，根据 SOP 运行时细小的差异来进行优化。」而 Agent 时代这套方式彻底失灵了，「因为根本就没有 SOP」。每一个由 Agent 执行的任务，都要根据任务环境单独设计和调试 harness，无法复用同一套规则来节约大脑运算的能量。

他打了个比方：古法与 Agent 模式，差不多是「缓存命中」与「全新输入+推理」的差异。节约脑力是普通人的生物本能。

翻成人话

大多数人上班在干什么？把一招练熟，然后重复一万遍，越干越省劲，闭着眼都能干。这是生物本能，大脑能偷懒就偷懒。而用 Agent 干活完全反过来：每次任务的规则都要重新想、重新调，环境一变又要改，大脑一直处于思考模式。纯银说，这种活大多数人不愿意干，「太累了」，他们摇着头告诉你。

落到你身上：你就是文章说的「思维活跃、乐意支付脑力」的人

文章里有一段几乎是在描述你：「第一批拥抱 Agent 的人同时也是思维活跃，不吝惜脑力，甚至乐意于支付脑力的人。」你数一数自己干过的事：97 条动态示例、57 条 V3 全量、33 个 case 的 A-F 分诊、SP 优化专项（3.3 万 token 往 1.6 万压）、触发器 20 条高频条件初稿、每天读文章还要我按七段格式拆解。这些全是「没有 SOP、现编 harness」的活，全是烧脑的活。

更关键的是文章后面那半句：「不匹配大多数人的工作方式。」看看你身边的同事：韩杰有韩杰的 SOP（原料层只管供给），刘杨有刘杨的 SOP（平台只认 10 个运算符），端上的人有端上的 SOP（scope 收窄回 CDC）。你在做的事（把场景定义权拿到手、让触发后的动作归 Planner 推理）本质上是在改他们的 SOP，他们当然不配合，因为配合你的代价是持续烧脑，而省脑是本能。7.10 评审你被截胡，不是他们坏，是他们遵循本能。

你该干什么

认清一个事实：你是少数派，这是资产不是负担。但少数派的资产只有在「能被看见」的时候才值钱。你打磨 harness 的成果如果只躺在文件里，等于没打磨。这一节对应行动清单第 1、2 条。

03

第二个论点：鸡生蛋蛋生鸡，Agent 工程师供给不出来

原文说啥

如果 Agent 模式能提效 3 倍，公司可以裁到 1/3，只留熟练的 Agent 工程师；或者招少量 Agent 工程师设计规则，其他人运行规则。但前提是市场得供应起码数量的 Agent 工程师，这批人必须同时掌握两样：Agent 驾驶技术 + 公司业务，缺哪样都不行。

纯银列了个死循环：公司不推行 Agent 模式 → 工作环境培养不出 Agent 工程师 → 没有 Agent 工程师 → 公司没法切换到 Agent 模式。外招的人「懂 AI 不懂业务是驾驶不了 Agent 的」；内部培养的隐藏 bug 是「如此大幅度提效必然带来大幅度裁员，谁上谁工贼」。

翻成人话

公司想用 AI 提效，得先有会用 AI 的人。但这种人既懂 AI 又懂业务，市场上没有现货（外面懂 AI 的不知道你们业务怎么跑），自己培养又得罪人（你教大家用 AI 提效 3 倍，提效之后裁谁？先配合你的人就是工贼，同事明里暗里使绊子，最后他自己也可能被裁）。所以大家都不动，死循环。

落到你身上：你的处境比文章写的更具体

文章讲的死循环，你正在用肉身演一遍：

你是那个「懂 AI 又懂业务」的人：SP 你拆过（round4 真身）、示例你写过（97→57）、bug 你分诊过（33 case）、信号你定过（上汽米/秒/hh:mm）。全组同时懂两样的人不多。

你的阻力就是「谁上谁工贼」：你推触发器场景归产品定，韩杰说「和泽民对齐过了」把定义权接走，刘杨抓着「切入切出」不放。他们防的不是你这个人，是「你改规则 = 我持续烧脑 + 我的地盘缩水」。上次《需求爆兵》里说过同样的话：他们算账算得都对。

你的孤立无援也是文章预言的：「一个部门内有少量的 AI 信仰者，自己的日常任务尽可能多用 Agent 实现。其他人的任务，他没有权限干预，同时因为对别人的业务陌生，他也不知道怎样改造。」你在 Planner 模块的提效（ACC 88.38%、首包 998ms）没人否认，但一跨出 Planner，别人说你管不着。

这里有一个重要判断给你：你不该把「推改革」当主业，那是最难的一条路（文章说 99.9% 的公司都推不动）。你该把「当 Agent 工程师」当主业，把成果经营成看得见的资产。改革推不动不是你的错，是结构决定的；但资产经营得好不好，是你的选择。

你该干什么

停止用「推动全链路人用 Agent」来证明自己（那是 99.9% 都会失败的路），改为「把自己打磨成最值钱的那个 Agent 工程师，让成果可展示、可带走」。对应行动清单第 3、4 条。

04

第三个论点：只有两种公司切得动 Agent 模式，你该押哪边

原文说啥

纯银说两种公司会向着 Agent 模式大步迈进：第一种，老板对前沿技术着迷，宁肯承担业务风险也要狂热拥抱；第二种，AI native 新项目，没有历史包袱，由狂热的 AI 信仰者组成，而且这种项目根本不在乎提效后裁员，大家真正担心的是项目挂了全体失业。他引用小扎 7 月内部讲话做反面佐证：「过去四个月，AI Agent 的发展速度并没有像我们预期的那样加速」「我们希望从新的组织结构中获得的收益，目前还没有实现」，Meta 这种巨头都卡在历史债和复杂协作链上。

翻成人话

老公司切不动：收益看不清、成本看得见、风险吓死人，99.9% 的公司只能喊口号「多用 AI」，实际上业务和 Agent 一点没匹配上。能切动的只有两类：一个狂热老板单点拍板的公司，或者从零开始没有历史包袱的新公司。小扎的话证明连最强老公司都在原地踏步。

落到你身上：这句对你特别重要，它重新校准了你的职业判断

第一，你在字节的处境。字节大、链路长、历史债厚，就是文章说的「99.9% 的老公司」。你在里面推触发器场景归产品定，推的是老公司的改造，难是结构注定的，别把推不动的责任全背自己身上（你之前复盘「7.10 全场只说两句」背了很多自责，这篇告诉你：结构因素占大头，个人因素只占一部分）。

第二，你转具身智能的方向恰好是文章说的第二种公司。具身智能的公司基本都是 AI native：没有历史包袱、全员 AI 信仰者、全员担心项目挂了失业而不是被 AI 裁员。纯银说只有这种环境才能切 Agent 模式，而你想去的地方正是这种环境。这篇文章等于给你的职业规划背书：去 AI native 新项目，是少数几条走得通的路。

第三，小扎那句话也是给你的提醒。连 Meta 都承认 Agent 落地慢于预期，说明「Agent 落地慢」是全球现象，不是你个人的能力问题。你 7.24 评审拿了 60 分就自责，这篇告诉你：整个行业都在同一个泥潭里。

你该干什么

把职业判断从「内部推改革」切换到「攒资产，瞄准 AI native」。对应行动清单第 5 条。

第四个论点：局部提效 ≠ 整体爆兵，你的 5X 被协作链吃掉

原文说啥

「AI 带来的局部效率提升不能转换为整体效率爆兵，在因循守旧的协作模式下，个别任务 5X 也好 10X 也好，对整体生产效率并没有多大改变。」纯银说，一个部门内有少量 AI 信仰者，自己的任务尽可能用 Agent 实现，但别人的任务他没权限干预、也不懂别人的业务，能带来整体效率提升的任务必然要改造大量多人协作环节，每一个改不动的环节都是绊脚石。个别信仰者「什么都推动不了，什么都证明不了，他只能匹配自己闭环完成的那一点点」。

落到你身上：这条最扎，但恰恰给出路

你对号入座一下：你的 Planner 提效数据（SP 优化 ACC 88.38%、首包时延减半）是全链人承认的，但线上整体体验的提升被什么吃掉？被上汽 610 的验收节奏、被端侧 scope 的反复、被信号格式的等待、被评审排期吃掉。你的 5X 变成整体的 1.2X，然后有人据此质疑「优化了这么多，体验没质变」。

但文章同时给了出路，犬校同学的回帖里有一句被纯银单独圈出来的话：「大公司里最适合上车 AI 的方向，其实是内部工具，而不是任何一个业务部门。」你正好有一串内部工具的手艺：JIRA 一键流转面板（:8770）、视频翻译面板（:8765）、Claude 同步系统、配置平台 4 处待改造、信号中枢三表。内部工具没有外部协作链的羁绊，你自己就能闭环，提效看得见摸得着，这正是「自己闭环完成的那一点点」里最值钱的一种。

你该干什么

把「内部工具」当一条被低估的主线来做：挑一个能闭环的内部工具（配置平台改造或信号三表），做到全组离不开，这就是你在大厂内部最实的 Agent 资产。对应行动清单第 4 条。

三句话带走

一，大逃杀推迟 5-10 年，卡点不在 AI，在人：大多数人靠 SOP 省脑力，Agent 时代没有 SOP，只有愿意持续烧脑的少数人配当驾驶员。你恰好是那个少数人，别把少数当异类。

二，你的提效是真金，但没变成外部性收益，等于打磨给空气看。收益账、提效日志、内部工具、边界文档，四样任选一件，把「自我追求」变成「别人看得见」。

三，推改革是 99.9% 会失败的路，攒资产才是你的路。具身智能公司全是 AI native，那是文章说的少数能切 Agent 模式的地方，也是你该去的地方。

纯银写完这篇，配了一首《十年》的歌词：「十年之后，我们是朋友，还可以问候。」他说十年后大逃杀才可能全面到来。对你来说，这十年不是等来的，是抢来的：你手里的 harness 打磨手艺、边界文档、内部工具，每一样都能带走。十年后不管在哪，能持续烧脑的人永远有饭吃，这跟大逃杀来不来没关系。
