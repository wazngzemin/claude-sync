触发器产品链路里的关键人 + 各自地盘（2026-07-23 梳理，用于决定找谁钉什么）：

- **韩杰**：信号中枢（Signal Hub）owner，管<b>原料层</b>——状态查询/条件/触发事件/动作四张原子能力清单（火山引擎_原子能力清单.xlsx）。原料归他，编排归泽民。补积木、补运算符、钉事件互斥口径都找他。
- **刘扬**：<b>触发器平台配置方</b>——把积木配成规则的人（配置平台/workflow画布侧）。运算符转换口径、缺积木导致配不了、频次策略在平台哪配、多选/互斥等配置层问题找他。7.10 他抓过运算符转换错误+反对"切入切出"（底层没实现）。<b>关键未决项：触发器平台到底有没有频控配置能力，频次归产品定还是平台给配置项——一直没钉死</b>。
- **益红**：场景需求方，给触发器场景表（如8条预设条件场景）。找她补场景表里的逻辑漏洞（如低电量漏导航状态、多人出游漏多人判断）+ 确认非车端信号的数据源。
- **丁彬 / 西钺**：视觉（VLM/VQA）。舱内数据严重缺失、视线已取消；舱外 VQA 识别能力（如后视能否识别充电桩）找他俩确认。西钺=配置平台视觉字段 owner。
- **仁杰**：端上报格式/单位约束 owner（赛力斯侧汪帅/金龙是端上执行）。端状态枚举值含义、信号单位（米/秒/hh:mm）找他推赛力斯标清楚。
- **赵衍**：领导层，7.10 当众三连递"端侧触发器要产品定"的授权给泽民（泽民没接住）。
- **张嘉锋**：专家任务集总组织者，分工派活（场景=芮婷如水/执行状态事件=韩杰/视觉=丁彬西钺）。
