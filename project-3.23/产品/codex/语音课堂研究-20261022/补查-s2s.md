# 豆包端到端实时语音模型ONE PAGE

## 🔍一、什么是端到端实时语音模型

<div class="callout">

**产品定位：****超拟人、低时延的实时语音交互模型**

- 豆包端到端实时语音大模型，对标 OpenAI GPT\-4o 端到端语音对话模型，聚焦中文对话场景（支持英语，暂不支持其他语种）。基于Speech2Speech 端到端框架，原生融合语音与文本模态，实现：

    - 超拟人交互：语音表现力接近真人，自然还原语调、情感；

    - 低时延响应：显著降低交互延迟，对话流畅无卡顿；

    - 强泛化能力：精准理解语音指令，生成内容灵活适配多场景。

**技术原理**

- 传统语音交互需经 “语音识别（ASR）→文本处理（LLM）→语音合成（TTS）” 级联流程，易导致信息损失。豆包端到端模型直接以音频 token 建模语音，在单一模型内同步完成语音理解与生成，省略文本转换中间环节，从源头避免信息损耗，实现 “语音输入→语音输出” 的极简高效交互链路。

**应用场景**

- 可应用于智能语音助手、智能客服、语音交互游戏、教育培训等需要实时语音交互的场景，为用户提供更加自然、高效和便捷的语音交互体验。

</div>

<div class="callout">

- **指令灵活控制：**支持自然语言高级指令调节，涵盖情绪表达、方言切换、语速控制、风格定制及声线模仿等多元能力，交互体验更个性化。

- **多模态演绎：**兼具歌曲演唱（多风格适配）与角色模仿能力，可生动演绎多元故事场景，沉浸式氛围感拉满。

为了对不同的场景提供适配的模型效果，S2S模型分为2个版本：

1. **S2S\-Omni版本（O版本）：**定位是一个低延时语音端到端助手模型，是一个支持语音/文本多模态，覆盖闲聊、客服、车载等ToB多场景的低延时端到端模型；

2. **S2S\-Strong Character版本（SC版本）：**强人格版本，是一个专注于人格扮演、情感陪伴的模型，核心能力在于支持**声音复刻**、人设一致性、对于声音的全局微调；**主要for角色扮演/情感陪伴场景**。
