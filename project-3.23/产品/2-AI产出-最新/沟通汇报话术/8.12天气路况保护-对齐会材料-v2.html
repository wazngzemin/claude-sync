开发的问题（原话）产品策略（答案）
VLM 每次输出都不一样，变一个字就通知？（李鑫 21:38）只盯 struct 里的枚举字段（"天气情况描述"/"路面情况描述"两个 key），不判全文。枚举没变 = 无变化，不通知。
第一个 5 秒识别到下雨、第二个 5 秒没识别到，算变化吗？（张荣 24:38）防抖：连续 2 个上报周期（10 秒）枚举一致才算变更成立。单帧跳变视为抖动，不触发。
触发后持续下雨，还重复触发吗？one-shot（一次性）：枚举跳变那一刻触发一次；持续不重复；切出再进入才再触发。
监控事件 ID 还是 ID 里的参数？（张荣 26:55）监控 struct 内指定 key 的枚举位（天气就盯"天气情况描述"），不是整个 struct 任何字节变化。
VLM 超时/本轮没上报算什么？超时不等于"无雨"。缺帧不参与防抖计数、不改写当前枚举（安全红线：禁止把 timeout 当"无异常"）。
