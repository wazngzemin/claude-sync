## 有实质增量的地方

1. 端云通道：音频上传 AIDV、由 Speech 识别，文本先回客户端，再经豆包文本链路进入 AIDV。文本回复与 TTS 音频分通道；音频缓存支持流式消费。状态/事件和 Frontier 不需绕进文本对话通道。
2. 版本隔离：旧 RTC 双流竞速、202607 文本方案、自建非豆包 IP 建设中分开呈现；不把旧“升级”文档标题当最新事实。
3. Context：知识、当前状态、召回、注入和实际采用分开。历史原文写“实时有效”是需求，不等于当前新鲜性证明。
4. 动态知识：query/context/loaded IDs → add/remove IDs → 取内容 → 注入 knowledge → 看 Director 行为与真实结果。与工具数量、当前启用状态分开。
5. 司机 Agent：Director/工具传递意图，智驾判断可执行性并负责动态驾驶安全；accepted/executing/completed/rejected/failed 不能合成成功。
6. 评测：检查点完成、pass@3、pass^3 与安全/隐私一票否决各有作用，不用一次成功视频代替稳定性。

- 动态知识示例中有询问“要现在导航吗”同时发导航动作的说做冲突；末尾又要求避免未等确认就执行。未把这种示例复制为正确教学结果。
- 司机 PRD 前部“用户中断优先级最高”与后附序列把用户取消排后存在冲突。
- 司机 PRD 一处说异常澄清当前暂无，后附状态机却含用户确认；不同部分还有不同视觉/距离/超时阈值和自动降级动作。没有据此给出当前安全合同。
