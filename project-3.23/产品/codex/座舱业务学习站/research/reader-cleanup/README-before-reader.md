## 从哪里开始

首页先沿“语音输入 → 入口与端云采信 → 输入管理 → Context → Planner/Director → 工具与反馈 → 用户结果”理解交接。直接回答可以绕过工具执行；工具反馈会重新经过输入管理与上下文准备，再由 Director 判断，不能把工具输出当成用户目标已完成。

首页先用“去昨天那家游泳馆，十分钟后提醒我休息”连续讲完主要过程，把 24 个模块放进同一段业务理解。进入每一课后，先看连贯正文，再看完整图及紧随其后的带读。讲解直接指出实际节点、分支条件和下一站；例如 V12 → R1 交正式输入，R9 → R12 → C5 同步本地真实结果，V8 → V18 是识别失败出口。

62 张图均有独立的连续带读。放大图时，右侧同步显示同一份讲解；窄屏上下对照，讲解可收起。原节点、来源、版本比较和逐项审读记录仍可展开，旧链接会自动打开相应折叠区。全部旧节点和连线保留。

也可以先进入首页“同一句 Query 完整走查”：四个场景共 48 步，每一步都保留已知/未知、输入、判断、输出、下一跳、完成证据和失败去向。点击步骤只定位，不隐藏前后文；这是来源化教学，不是伪造的运行日志。

重点入口：

- Memory：身份、生成、召回、采用、管理和隐私边界。
- 事件：事实怎样产生、哪些事实进入当前推理、打断事件的版本差异。
- 事件日志：保存、查询、订阅、记忆生产、诊断和治理。
- 自进化：个人偏好、个人技能、平台规则和模型优化的区别；评测、放行、受控验证与回滚边界。
- 工具页：输入、机制、返回状态、异常、下一步与完成证据。来源表条目数不是当前车型可用工具数。
- 司机 Agent：独立于 Director 和 auto_drive；导航泊车、POI 临停、取消旧泊车再改临停三条流程，保留用户选择、地图映射、二次确认与真实执行。
- 端云交接：ASR 识别文本先回端，再经豆包进入汽车业务；回答文字与 TTS 合成并行，音频凭关联标识单独取流。
- 事件字典：12 张工作表的读取范围与 66 条定义记录、64 个不同 ID，明确未支持项、重复 ID 和字段差异；不是线上事件能力数。

每个模块还有场景案例、关键问题及参考答案、指标定义、后续方向、来源和本地笔记。学习进度需主动标记，打开过不等于掌握。笔记仅保存在当前浏览器；换版本文件或浏览器后不保证自动共享，请及时导出 Markdown。
