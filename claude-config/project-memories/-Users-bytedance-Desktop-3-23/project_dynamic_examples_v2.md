**格式教训（重要）**：第一版用【定位】【查】【分支】【边界】【调用】五要素符号堆+箭头+"同XX链"跨行引用，被泽民骂"瞎写乱七八糟"——动态示例必须保持原表一句话人话风格。定稿格式："结合XX具体状态（字段名）：情况A就改写为"…"；情况B则改写为"…"。调用工具。"每条自包含，禁止跨行引用，最多两个主分支。

**Why**: 这表是按条检索注入SP的，单条注入时模型看不到其他行；且注入后要和SP里其他决策分析口吻一致。
