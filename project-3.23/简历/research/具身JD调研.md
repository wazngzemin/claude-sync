# 具身智能产品经理真实 JD 调研与需求矩阵

调研日期：2026-11-17（北京时间）｜目标时间窗：2025-11-17—2026-11-17｜范围：只调研、只给简历覆盖方向。

## 1. 先看判断

基于本次岗位样本与用户提供的经历，最值得优先展开的是：把真实场景变成机器人可执行任务、跟进执行结果、用数据与评测推动改进。Planner、舱驾融合、主动服务、训练与 UX 经历分别能提供这条链路的不同证据；后续写简历应围绕实际负责的环节和结果组织。直接对应的例子包括[逐际 Agent 岗](https://jinliqiuzhi.com/jobs/475777)、[智元具身模型岗](https://jobs.ivyea.com/jobs/19677)和[1X 数据岗](https://jobs.type1ventures.com/companies/halodi-robotics/jobs/84350000-lead-technical-product-manager-data)。这是匹配判断，不是对用户尚未提供的成果作事实认定。

“具身智能产品经理”包含模型、Agent、数据平台、交互、行业方案、系统平台和硬件等不同职责。主样本中，产品规划及跨团队推进各出现 23 次，场景需求 21 次；明确写到任务规划与 Agent 编排的只有 1 次，另有 2 条日期证据不足的补充岗位。这说明 Planner 是值得定向展开的差异点，不能据此把所有具身产品岗位都描述成规划大脑岗位。

### 收集规模与日期口径

- **主样本 23 份，覆盖 17 个公司/团队**：每份都有落在目标时间窗内的公开发布日期记录。2 份日期来自官网或官网搜索索引，4 份来自高校招聘页，17 份来自明确标记 Posted / 发布于 / 职位日期的第三方岗位页或列表。
- **另列 13 份补充 JD**：有职责证据，但只找到相对时间、更新/收录时间、未明确含义的日期，或完全没有日期；不计入“近一年发布”主样本。
- 合计记录 **36 份独立 JD**。23 份主样本中，20 份在至少一个列明来源能读到职责及任职要求全文，3 份仅摘要；“转载全文可读”不等于“官网原页全文已核验”。
- “近一年”采用**近一年公开发布记录**口径；第三方日期不能证明官网首次发布日，也不能证明现在仍在招。1X 数据岗已停止申请，仍保留用于需求研究。若只接受官网首次发布日期，本轮证据不足 20 份，不能把这 23 份说成全部已核验官方首发。

检索先覆盖 BOSS 直聘、猎聘和公司官网；BOSS 独立页多触发安全验证，部分官网是动态页，联网工具只能读到搜索索引。为补足正文与日期，再使用可回溯公司招聘入口的同步页、高校企业招聘页和投资机构职位板。全程只使用联网搜索及其正文读取工具，没有启动 Chrome、Playwright 或任何 headless 浏览器；未登录、沟通或投递。Anysearch 接口不可达后，使用可用联网搜索工具继续完成检索。

术语说明：JD 是岗位说明；PRD 是产品需求文档；Agent 是理解目标、安排工具或技能执行并跟进结果的智能体；VLM 是结合图像与语言理解的模型，VLA 进一步关联机器人动作；世界模型用于学习或预测环境及动作变化；Eval / Benchmark 指评测与基准测试；HRI 指人和机器人的交互；仿真与 Sim2Real 指在虚拟环境验证并检查结果能否迁移到真机；API / SDK 是供开发者接入能力的接口与软件工具包；POC 指小规模概念验证。
