注入方式
在ark调用参数新增：

type ArkModel struct {
    *ark.ChatModel

    ModelConfig ark.ChatModelConfig

    SystemPrompt          string             // sp，不传则尝试从fornax获取
    SystemPromptVariables map[string]any     // SP的变量
    Messages              []*schema.Message  // 消息，user query也得放这里，为了支持复杂的消息编排
    Tools                 []*schema.ToolInfo // tools 调用
    Channel               string             // 渠道
    AccessKey             string             // AK
    Secret                string             // SK
    FunctionKey           string             // 功能key，用于取模型信息、标记debug info等
    ModelName             string             // 模型名称
    ModelVersion          string             // 模型版本
    SPHardening           bool               // SP加固注入
}
在上述2个场景，这里参数传入true
对于传入true的场景，底层统一判断，如果sp中本身有security_hardening_prompt变量，则注入到这个变量里
如果没有这个变量，则直接追加到sp末尾
