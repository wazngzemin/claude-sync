# 背景
记忆和车机中存在一部分的信息重叠，比如：
1. POI类：家、公司的地址
2. 车牌
3. 通讯录
4. 座椅收藏信息
为保障体验的一致性，二者需要有同步机制。
# 方案
## 短期方案
短期方案主要实现：**家/公司由记忆向系统地图的同步。**
用户存在以下两类表达：
- **偏记忆：**
    - 你记一下我家的地址是思南公馆西苑
    - 你记一下我公司的地址是漕河泾中心D栋
- **偏设置：**
    - 把思南公馆西苑设为我家的地址
    - 把漕河泾中心D栋设为我公司的地址
    - 帮我找下那个多抓鱼 \-\-\-\&gt; 第二家帮我收藏一下
短期方案为：记忆工具对接收到的语义进行分流，家/公司设置相关的分流给提槽模块，工程校验提槽模块输出结果，完成家、公司地点设置。
## 长期方案
增加【同步Profile推理模块】，由一个模块统一接收、仲裁记忆和车机中重叠信息（家/公司、车牌、通讯录、座椅设置等）的变更，并完成记忆和车机内容的更新互通。此外，在【[语义记忆画像算法方案](https://bytedance.larkoffice.com/docx/PdfEdR6Mzo77xvx6MpIcbyfWn4e)】的基础上扩充【同步Profile内容】，完善该模块定义。
