豆包汽车：从语音 Query 到用户可见结果

主路径 + Planner 回流 + 条件任务分支｜产品经理目标：主链路 L3，算法实现 L1–L2

你必须深入：L4

  • • Planner：任务拆解、依赖、追问、重规划
  • • Trigger：创建、等待、触发、取消、过期
  • • Feedback：失败语义、重试和状态校正
  • • 评测：端到端成功率与根因归属

掌握机制：L3

  • • 分流漏斗、Context组装和信息时效
  • • Goal / Task状态与工具调用契约
  • • 端云路由、幂等、打断、超时和降级
  • • 知道每层输入、输出、Owner和异常边界

理解接口即可：L1–L2

  • • ASR/VLM/端侧模型的训练算法不必亲自掌握
  • • 但要能读懂准确率、召回率、时延和置信度
  • • 不负责研发配置和实车执行，负责方案与验收
  • • 职业护城河是AI系统能力，不是模型名词数量
