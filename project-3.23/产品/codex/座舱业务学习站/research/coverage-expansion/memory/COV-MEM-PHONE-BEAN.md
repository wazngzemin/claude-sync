# 一、需求概述

## 需求背景

当前主流手车互联体验痛点\&amp;我们优势：

1. 【P0】体验不丝滑（操作路径长/繁琐）**→ 优势：预判需求缩短路径\&amp;支持模糊控制**

    - 利用豆包 C 端用户偏好数据，记住 “降温” 习惯，无需反复选参数

    - 支持模糊车控能力。如说 “凉快些” 自动调 25℃，不用选具体温度

2. 【P1】服务被动（需用户主动触发）**→ 优势：主动推送服务**

    - 利用用户行为数据，做精准服务推送/预约。如根据行程推 “提前开空调”，不用用户手动操作

3. 【P2】车端服务无法在座舱外延伸 **→ 优势：豆包跨设备同步**

    - 车端指令同步至多端。如车上聊的文章，可生成博客后在手机端/耳机续听
