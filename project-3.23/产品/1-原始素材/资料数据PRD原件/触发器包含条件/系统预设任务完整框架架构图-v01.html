一个状态真源

任务中心点击只是意图。接入业务真正保存后，端/云 Runtime 才能按 ENABLED 运行。

一种拓扑，一个产生方

链路可为 EDGE、CLOUD 或 HYBRID；但同车、同任务、同版本只能由一侧创建本次 RunEvent，冲突时双方都停止。

一个 RunEvent

硬候选通过后先建事件，再调模型或出卡；条件、模型、卡片、授权、车控和回读必须用同一事件关联。

一个成功真相

Query、FOUND、点击、Planner 选择、RPC ACK 都不是最终成功；真实车辆状态才是。

端侧与云端怎么分

决策问题端侧云端/端云混合共同底线
主要输入本地车况、端侧 VLM、明确枚举合规上行状态、多源上下文、DT/VQA、开放语义都有时间、质量、车辆和事件关联
核心判断AND/OR、阈值、变化沿、状态机推荐准入、语义、模型、工具编排UNKNOWN/过期都不能继续执行
典型任务EDGE天气/路况保护HYBRID识别充电设备后开盖HYBRID 仍需唯一 RunEvent producer；用户确认后仍回端侧复核
语音可见即可说 → 模拟点击原按钮Planner + 当前卡片上下文结果必须带同一 RunEvent
最终执行端侧复核 → 赛力斯车控 → 回读云端下发 → 端侧复核 → 赛力斯车控 → 回读真实状态达到目标才成功
