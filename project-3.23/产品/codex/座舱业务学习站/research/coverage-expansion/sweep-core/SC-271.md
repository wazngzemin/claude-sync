# 250709\-表情提取

# 背景

在AI汽车中，展示豆包回复内容的表情。

# 数据

[表情提取数据集](https://bytedance.larkoffice.com/sheets/V4H4s1nAihiMkntVaDcc9ofln1b)

# 规则

从AI助手的回复内容中提取表情。每次只提取最多1个表情。提取对象是AI助手的回复，而非用户的情绪。因AI助手轻易不表现情绪，因此当助手的内容含有微情绪时，也需要提取出。当助手的回复没有表情时，返回“无”。

待标注内容：待标注信息：info1\-N

其中，query是用户问题，text1\-N是模型流式输出的回复， info1\-N是对text1\-N的表情提取结果。

流式提取过程中，当截断的内容不完整时，只提取前面已经语义完整的内容，缺失内容不用提取。

### 表情类别

```Plain Text
认可
祝贺
快乐
否定
悲伤
愤怒
惊讶
厌恶
恐惧
轻蔑
羞耻
困惑
无

安慰
担心
```
