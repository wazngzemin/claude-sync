# 12 T 任务中心 — 资料里有、副本需补/修正的事实点

## 任务中心定位（副本 N16/20 有雏形，需补"不执行业务逻辑"边界）
- 任务中心 = 异步任务统一承载与回溯入口；即时交互由 VUI 卡片承载，无法即时完成/需等待触发/持续执行的任务进任务中心（白名单）。
- **不执行业务逻辑**：用户点暂停，任务中心只更新组件反馈+通知业务方，任务是否真暂停由业务方回传。
- 来源：DNA-SOP 任务中心 docx ZxnEdWdBXowoNTxADZjc7vWjnNf。【2.6目标】

## 服务端=聚合代理（副本 T 章没画这个形态）
- 对端收敛 3 个接口：列表 / 删除 / 状态开关；任务变更主动推送。
- **只有出行和舒适类子目标出现在任务中心**（弋途侧叫子目标）；内容和情感类不出现。
- 来源：sls 任务中心技术文档 docx E5xww8E3kiDv3RkVjDxcmKxqnFe。【2.6目标】

## 任务类型与状态机
- 全量状态：创建中/进行中 running/暂停中 paused/已完成/已取消/失败；任务中心只展示 running 和 paused。
- 任务类型：定时/循环定时、条件/循环条件、通用长时任务（目标 915）、静态 advisor 子目标、系统预设任务（雨天湿滑模式）。
- 来源：任务中心 PRD docx LUKKwMTNaiAd53kdmpkc5oILn5e。【2.6目标】

## 与触发器/Advisor 的边界
- 静态 advisor 子目标（出行/舒适）+ 系统预设任务在任务中心展示；产生逻辑由弋途和触发器负责，不在任务中心服务端范围内。
- 用户开关：默认全渠道开启，支持按需启停；开关状态不需要告诉云端（逐字稿 Mijvdy2hJo9Pv5x1ATRcvn0BnEe）。【讨论中】
