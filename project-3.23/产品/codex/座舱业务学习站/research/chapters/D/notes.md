## 三、演进 / 取舍 / badcase / 争议
- 演进：意图分类 + 简单复杂仲裁 + NLG → 一个 ReAct 模型（逐字稿 00:05:03，“串联的东西更多…出错的概率也就更高”）→ 10/20 群里又讨论复活“简单复杂仲裁”（速度慢是上汽 TOP1，notes-chat）→ 赛力斯后续“DT 后面要承担拒识”（M30，长期）。
- 演进：全靠 SP（PE）→ 动态示例 / 场景知识 / 能力说明按需注入 → 后训练（SFT+RL），原因是提示词长度稀缺、幻觉压不住；代价：话术活人感可能掉（盲测 SFT 排末位）、评测口径未统一。
- 取舍：去掉“要不要说”字段换首字；能力边界检查因性能未准出；2.1 lite fast 因话术质量暂停；表情并入话术有性能负收益。
- badcase：JSON 38/4000；字段顺序；虚假成功（先说已关 AI 画布再说没找到）；先说不能后又能（地图收藏夹）；授权顺序反了（自适应巡航）；SFT 不建持续目标；SFT 在 D 挡调主驾靠背。
- 争议：表情和情绪标签怎么评；SFT 是否比 PE 好（不同报告结论不同）；灰度比例；司机 Agent 是否放在 DT 里。
