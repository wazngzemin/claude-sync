# 系统预设任务三张详细 Mermaid 业务流程图 v14

本目录包含三张可直接复制到飞书 Mermaid 代码块的业务流程图：

1. [01-系统预设任务完整业务框架.mmd](./01-系统预设任务完整业务框架.mmd)：从产品定义、配置、任务中心启停，到端云判断、卡片交互、车辆执行和结果回传。
2. [02-端侧天气路况保护完整业务链路.mmd](./02-端侧天气路况保护完整业务链路.mmd)：以天气／路况保护为例，讲清端侧 Trigger、天气原业务、即时交互卡、可见即可说和赛力斯车控的分工。
3. [03-云端充电设备识别开盖完整业务链路.mmd](./03-云端充电设备识别开盖完整业务链路.mmd)：以充电设备识别后开盖为例，讲清 Cloud Trigger、Advisor／DT／VQA、原业务注册卡片、Planner语音理解、端侧执行和真实状态回读。

对应的 `.svg` 文件可无限放大检查，`-预览.png` 用于快速查看整体结构。

本版统一采用以下产品口径：

- Trigger 负责判断“什么时候发生”，只产生业务事件，不直接拉卡或车控。
- 原任务业务负责“发生后怎么处理”，包括注册卡片、消费用户结果、发起执行和收口。
- 即时交互卡负责受理、排队、真正展示、TTS、按钮与生命周期，不判断场景、不决定车控。
- 端侧卡的语音走“可见即可说”，命中当前按钮后模拟同一按钮点击。
- 云端卡必须由业务方先注册并真正展示；Planner 不直接拉起卡片，只按需理解当前卡片下的泛化语音。
- 最终成功以真实车辆状态回读为准，不以按钮点击或车控请求受理为准。
