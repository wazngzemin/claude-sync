# 触发器后台方案原型：操作规则与评审要点

本目录包含 5 张静态、低保真方案原型，不代表当前平台已经实现或上线。所有页面均为 1700 px 宽的原生 SVG，可用于飞书画板转换；PNG 是渲染核对副本。未新增 Timer、工具、卡片确认或车控判断节点。

依据：刘杨《触发器支持系统预设场景》技术稿 3.2—3.4、3.6—3.8，以及 v04 PRD。与实际界面或接口未完全一致的控件、默认值、可修改范围，应在评审后收口。

## P1：场景列表与范围

用户先按渠道、环境、名称或 ID、状态、来源、触发类型和普通／预设分类筛选，再通过新建入口选择简单或 Workflow 模式。模式不等于走／不走 DT。生效范围点击后在弹窗展示车型、客户端版本及车辆范围，不把过长内容挤在列表中。

列表展示场景 ID、名称、模式、渠道、环境、范围、更新信息及状态。环境来自服务端部署标签，筛选不改变环境隔离。既有 Workflow 暂不能直接修改判断定义，原型保留查看、复制和删除入口；删除的权限、关联提示和影响沿正式方案确认，不能自动删除用户任务选择。无匹配数据时提供调整筛选或新建引导。

## P2：简单模式编辑

页面把“什么更新会启动检查”和“检查后还要满足什么”分开讲。充电案例用档位变为 P 作为动态条件启动；进入本次检查后，仍检查当前任务、主动服务、SOC 和口盖状态。

静态条件可选不代表规则可以全部为空。合法启动存在时可以没有附加静态条件；启动与判断均为空则阻止保存并定位错误。实际启动信号清单由规则生成，显示真实 ID，不另维护第二份。缺失、未知和过时不能当作满足。

## P3：Workflow 画布与校验

画布为四个真实判断节点：N1 公共条件 → N2 后排儿童条件 / N3 后排宠物推理 → N4 儿童锁未开启。OR 配在实际终点 N4 上，而不是新增空白汇合节点。N4 的直接前驱已有两个，因此可选 OR；N2 或 N3 任何一个 PASS 只允许 N4 开始，N4 自身的儿童锁关闭条件仍需通过。

用户添加条件或推理节点、连线、选中节点后在属性区填写。后排位置和年龄属于同一乘客对象；宠物判断使用已接入的物体描述，不用假定宠物布尔信号，不调用 DT / VQA 获取新画面。

校验检查节点配置、ID、边、自环／重复／循环、可达性和唯一终点，服务端一次返回全部问题。示例展示 N3 缺少推理信号的保存错误：点击错误定位属性区，失败不生成可用 Workflow ID，不产生可发布的半成品。既有 Workflow 的编辑限制保留，不承诺无损切换或原地修改。

## P4：主动推荐带交互卡配置

动作选择 recommend_with_card 后填写 advisors_input 固定建议 Query，显式控制 enabled 和按钮。充电 Query 只陈述已知的停车、SOC、口盖状态，把检查设备交给 DT / VQA；明确发现后再询问，不能提前写成“已发现设备”。

后台不新增自由编辑 content 的输入框：content 由 DT 生成；TTS 沿已有下游链路。当前按钮示例确认／取消，数量与自定义范围待接入方确认。关闭带卡不代表允许静默车控。右侧预览是最终提交参数，不是最终端侧卡片效果。

策略采用现有可验证次数和最小间隔能力，不擅定新默认。simulator_supported=false，因此使用真实测试环境完成下游接收、卡片展示、用户回应和执行结果的分段验收。建议为空、参数解析失败或带卡按钮不合协议，定位字段并阻止发布。

## P5：本次运行详情

scene_id 对应场景，workflow_id 对应不可变判断定义，run_id 对应这一次运行。详情的输入、动作和策略快照展示本次实际使用内容，而不是当前最新配置。运行阶段和业务判定结果分别展示：FINISHED 可对应 PASS、REJECT 或 UNKNOWN；FAILED 对应 UNKNOWN；SKIPPED 显示阻断依据。

示例 N2 在 40 ms 先满足，N4 按 OR 立即运行并在 50 ms 满足；N3 到 1800 ms 才以模型异常结束。整图仍等全部节点终态后收敛，最终结果取唯一终点 N4 的 PASS，不按通过节点数量投票，不因 N3 异常改称“明确没有宠物”。

最终 PASS 后才进入策略和执行锁检查。History 先创建待处理记录，全部 Action 结束后更新结果。策略拦截、下游接收、卡片真正展示和车辆真实执行分别表达，没有真实回传时显示尚未确认，不把后台 Action 成功当作车辆成功。

## 布局与校验

- P1：1700 × 1030；筛选和列表在主体区，范围弹窗在右下，不遮挡关键行。
- P2：1700 × 1120；四段由上至下，错误提示在页底，保存按钮在规则后。
- P3：1700 × 1150；左侧 885 px 画布，右侧 490 px 属性；连线不穿其他节点。
- P4：1700 × 1120；左侧填写动作、Query、卡片参数和策略；右侧请求预览与真实联调提示。
- P5：1700 × 1130；顶部标识与快照，中部节点表，底部三类独立结果。

5 张 SVG 已通过 XML 解析；5 张 PNG 已生成并逐张检查，正文不被边框截断，节点及主要操作清晰可读。
