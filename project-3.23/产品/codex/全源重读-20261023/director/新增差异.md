# 相对 v14 的新增和纠偏清单

2026-10-23。以本目录 claims.md 中逐条源链为准。本次不是给 v14 扩字，而是修正版本/状态/连线含义。

1. **Context 的主线画错风险最高。** 当前 OnePage V2 是预注入+动态查询两路，已去掉统一精筛；不能把 C 的所有供给来源画成串行必经。根代理已逐段看原图：记忆预注入内部有用户画像并行于 query→标签→记忆列表与得分→过滤；信息不足才显式关键词/时间检索→再推理。该算法只在原图记忆示例成立，不可推广给全部数据源。
2. **身份和记忆应独立成区。** 姓名↔座位映射、账号↔车辆↔乘客、可信角色授权、多人过滤、记忆开关、异步生产、删除联动都不能压成 C 内一个“记忆”框。
3. **不能绝对写“记忆不支持删除”。** 10/19 v1.10 已增加车主语音删除需求，批量二次确认；当前发布/工具表仍需核验。删除后台能力与语音工具边界分层写。
4. **记忆关闭不是数据删除。** 旧记忆冻结召回，近轮对话还能基于刚说过的内容回答；新乘客上车摘要敏感信息清理单独画，未知乘客换人但人数不变是已知覆盖缺口。
5. **记忆受理不是生成成功。** 测试方案明确异步生成，pending/success 区分，查库/召回校验是独立证据。画像更新、用户改名和共享乘客同步另有回路。
6. **输入层需要“预算”和“允许外显”两个门。** 新设计允许上一轮播报中先算候选，不允许抢播/新副作用。原图“一切等 TTS 后再推理”过度串行化。
7. **已下发工具后不可重放旧输入。** 未出首 token 也可能已执行工具；打断声音≠撤回工具。旧结果要进入事实，不能新旧链都再执行。
8. **P1 队列/合并有文档冲突。** Input PRD 与10/22技术矩阵不同，不能自选一个当最终；把待确认标在分支上。
9. **终态不能用一个完成字。** 模型输出、工具批次、Agent流、真实车控/交易、客户端播放各自结束；播放超时解锁不等于播放成功。老60秒/20步参数不可当当前统一合同。
10. **工具数升级但不能宣称“40可调用”。** 最新PRD标准化表33业务行/34英文标识；根代理浏览器核验工具表40业务行（表2–41）。两张表版本和粒度不同；有旧声音演绎/豆包音乐弃用、空描述、测试/渠道差异。应保留来源行号和旧→新别名。
11. **工具加载与实际实现独立。** 定义—实现—渠道/环境—已发布启用—是否参与Director—权限检查—运行条件，不能一个“工具路由”框跳过。
12. **新增动态工具支路。** current_page_specific 随实时卡片条件加载；按钮名/card_id/selection流需画，agent_id TBD。inner_thought_update 是新需求，不能混进当前工具总数。
13. **三路输出与回退方向。** Agent content给UI、tts_content给语音、model_content给Director。根代理已看原图：Fallback回Planner重规划，Redirect指定下个Agent让调用方调度；不等于统一自动重试。最新统一播报要求与历史direct_return实现按渠道标。
14. **具体工具的业务结束条件不能同质化。** 停车二维码→用户扫码付款；餐厅提交→待商家→确认；录音→上传→生成→结果卡片；生图异步结果可在打断后送达；问题上报created/received/uploaded三个状态。需真结果，不能以工具“success”概括。
15. **停车技术文档工具名和标准化名不一致。** search_and_pay_parking_fee vs parking_fee_pay，别名映射待实际Agent配置确认。注册/续费与费用查询内部串行、失败不继续。
16. **车控参数有运行时字典。** 用户自定义应用/座椅位置/场景/联系人词表上报，车型/车辆隔离；参数分隔符存在文档矛盾，需接口确认。
17. **车书不只有独立工具。** 技术方案常用QA前置Context、Top3低置信过滤，并明确禁用旧工具；最新PRD又列必选。必须标项目/版本，不能合成全局必走或已彻底废弃。
18. **动态示例平台二期不等于已实现。** 9/3逐字稿明确当时只有车企/环境已上线，车型/舱内外/查重/审批/批量未开发。表I/J空白不代表工具没有别处定义；personal_skill_record在指南有协议，执行实现仍未证实。
19. **评测要有官方目标和自测问题。** 14维可用率3/4分准出表已读，加入对应模块。强多轮“闭环”包含正确失败结束，不可与真实成功率混用；首token≤500/800ms不是首音。
20. **不得用“已经全读”粉饰缺口。** 本目录inventory区分已审业务正文/仅抓正文/部分/权限失败/图像未看；根代理图像补证应另标。安全工程、弱网、异步反馈、部分账号和FC协议权限失败，仍待责任人确认。
