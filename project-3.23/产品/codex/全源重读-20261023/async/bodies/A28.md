### AIDV同步VLM信号到Trigger

当前已有链路：`\`biz/service/context/source/signal/resource/report\_scene\_type\.go\``

同步原始数据给触发器，触发器将原始数据反序列化成结构体用于条件判定，原始数据用于模型推理。

结构化数据格式复用 `\`biz/service/context/source/vlm\_description/business\.go\``的`\`ChangeToSceneDescriptionPack\``的处理，IDL如下：

反序列化代码示例：

```Thrift
func *unmarshalRawData*(ctx context.Context, vlmDesc *model.VehicleResourceInfo, scene context_info.SceneDescriptionPack) context_info.SceneDescriptionPack {}
```

1. 注意转结构化数据时需要[\[一期\]条件触发屏幕系统静默信息展示服务端技术方案](https://bytedance.larkoffice.com/docx/Bl4AdeDEqoyar7xAL7QcG3Bbnyh#share-HaVxdoAnFoydjExmCbNcdkhCnFb)

2. 执行条件判定时，需要将 in\_car\.normal\_frequency\_data\.passenger\_infos 结构的值转换成类似 \&\#34;vlm\_inside\_001\.主驾\.sex\&\#34;、\&\#34;vlm\_inside\_001\.副驾\.age\_range\&\#34;才能复用已有的规则引擎做比较，示例代码：

```Go
func changePassengerInfosToMap(passengerInfos []*context_info.PassengerInfo) map[string]string {
    const resourceID = "vlm_inside_001"

    result := make(map[string]string, len(passengerInfos)*3)
    for _, passengerInfo := range passengerInfos {
        if passengerInfo == nil || passengerInfo.GetPosition() == "" {
            continue
        }

        keyPrefix := resourceID + "." + passengerInfo.GetPosition() + "."
        result[keyPrefix+"性别"] = passengerInfo.GetGender()
        result[keyPrefix+"年龄"] = passengerInfo.GetAgeRange()
        result[keyPrefix+"造型描述"] = passengerInfo.GetAppearanceDesc()
    }
    return result
}
```
