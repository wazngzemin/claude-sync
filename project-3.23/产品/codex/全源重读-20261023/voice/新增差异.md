# 语音域新增差异：v14 需要补什么、纠正什么

日期：2026-10-23。基准为 v14/parts/voice.json 的 V/R/I 三模块；v14 不修改。所有具体证据及链接见 claims.md。

## 必须纠正的 8 项关系

1. **AIVA 9 月 30 日采信写得过于含糊。** 原 R2/R5 只写“本地结果暂不采纳/等云端”，遗漏确定性正则缓存仍优先，以及本地 LLM 在断网、云端 3 秒超时作为兜底。新图明确缓存 > 云端 > 本地兜底，并把云端迟到禁止再执行画出来。
2. **离线 ASR 文字采信不等于本地 LLM 语义采信。** 哪份字用于上屏、哪份语义候选可执行是两层判断；不能用一个“离在线仲裁”黑箱吞掉。
3. **未激活免唤醒不是严格等待 final 才上云。** 流式 attend 可提前上传，且已上传后本地最终 reject 不能撤回；云端最终结果接管。这条会影响拒识、带宽、时延与误触发。
4. **旧三层漏斗不再是统一必经链。** 本地缓存/可见即可说/FC/正式 Director 按车型分支；旧意图与简单复杂仲裁应作历史方案标签，不能重新插回所有用户请求。
5. **多人新 Query 合并不是取消所有旧工作。** 10 月 19 日用首 token 前后区分未输出推理与新一轮；已下发工具继续返回真实结果。卡片相关性 end frame 是另一机制，不能与合并窗口混同。
6. **拒识位置不是已经解决的事实。** OnePager 自身端云描述冲突；4 篇独立拒识材料权限拒绝。保留职责与接口，侧别标为车型/版本待核。
7. **打断恢复存在项目冲突。** OnePager 的 event 恢复与 AIVA VUI 最终拒识不恢复不能共用一个无标签出口；200 ms 淡出为 10 月 20 日讨论，未定稿。
8. **指标的终点不能偷换。** ASR 上屏、唤醒事件、唤醒声音、TTS 拉取首包、TTS 可听首声均不同。旧测试与 PRD 目标不得写成当前实测。

## v14 明显少掉的业务小模块

| 新补模块 | 应接在哪 | 不补会漏掉什么 |
|---|---|---|
| 麦克风授权与语音互斥 | 进入语音前 | 没反应究竟是无权限、通话抢占、禁用还是拒识 |
| 降噪/回声消除 | 原音频 → 干净音频 | 把自己声音、音乐、风噪识别成用户的根因 |
| 音区确认 | 声音输入 → Query 元数据 | 来源座位与目标设备位置混用 |
| 热词来源与实际生效 | 页面/车况/联系人 → ASR | 配了热词却未注入、旧页面热词失效、识别错人名 |
| 本地/云端 ASR 上屏与 final | ASR 输出 → 正式文字 | “先显示的字”不一定是“最终用于处理的字” |
| 未激活早召回与补音频 | 免唤醒 → 云端 | 流式 attend、最终 reject 的权限与责任 |
| 精确缓存与本地继承 | 入口 → 语义候选 | “暂停/继续”不是安全无上下文缓存 |
| 3 秒兜底与迟到隔离 | 云端未返回 → 本地/失败 | 双执行、双回复、长等待 |
| 本地历史完整回传 | 本地真实结果 → Context | “再调一点”没有上文 |
| 可见即可说完整链路 | 页面注册 → ASR → 匹配 → 业务点击 → 回执 | 不是“本地能点按钮”一句话 |
| 动态 selector 生命周期 | 结果卡片出现/退场 → 注册/注销 | 旧卡片仍被语音点中 |
| 多输入合并时间边界 | 有效 Query → 输入管理 | 误拒句打断有效请求、多人归属丢失 |
| 工具执行与 UI 状态并行 | Director 已调用 → 等反馈 | 思考、播报、工具不是串行三段 |
| TTS 选路/缓存/优先级/播放结果 | 话术 → 用户真听见 | 音频生成成功但实际没出声 |
| 车书兜底 | 语控不支持 → 查本车手册 | unsupported 被误讲成“车上没有” |
| 声纹注册与车外鉴权 | 特殊入口 → 正式 Query | 把声纹、FaceID、所有语音权限混在一起 |
| 车内外互斥与 ISD 验收 | 车外入口/输出 | 人数互斥已删方案被误当规则，接口通误当效果验收 |

## 产品经理可以据此实际追问的验收题

1. 用“打开车窗……不要开”证明预请求绝不提前执行；日志给出 pre/final 与采用 round。
2. 同一句话本地先返回、云端迟到，录像和日志同时证明只执行一次。
3. 断网后在本地做车控，恢复网络说“再调一点”，证明上下文真实同步。
4. 主驾问天气、副驾和朋友聊天，证明不误执行、错音区或丢掉当前有效请求。
5. 显示两个同名控件说名字，证明多命中澄清；切页后再说旧按钮，证明旧注册失效。
6. “取消刚才的提醒”必须展示取消回执且到点不再触发；只静音不算通过。
7. TTS 合成成功但系统音频抢占，证明状态没有谎称“已播报”；结束后恢复是否按项目规则。
8. 语控不支持但车辆有该功能，证明能查手册给正确手动入口，不编“没配备”。
